肝臟檢驗，先告訴你病人在哪裡
2026.07.18 小麻閱讀（9E）

閱讀 abnormal liver tests，最容易出現的錯誤，是把 AST、ALT、ALP、bilirubin、albumin 與 PT 排在同一列，彷彿它們都在共同衡量肝臟受損得多嚴重。

但這些數值並不是同一把尺。

AST 與 ALT 主要反映 hepatocyte injury。ALP 升高經確認來自 hepatobiliary source 後，主要指向膽汁形成與流動異常。Bilirubin 則牽涉從產生、處理到排泄的整條路徑。Albumin 與 PT 才比較接近肝臟的 synthetic function。

它們不是從輕微到嚴重排列，而是在觀察不同的生理環節。

因此，閱讀肝臟檢驗時，第一個問題不是肝臟到底好不好，而是：

目前主要被看見的是哪一個生理環節的異常？

當 ALT 相對於其 upper limit of normal 的升幅，明顯高於 ALP 相對於其 upper limit of normal 的升幅，屬於 hepatocellular pattern。當 ALP 相對占優勢，則屬於 cholestatic pattern。介於兩者之間，則是 mixed pattern。

Bilirubin 不參與這個 pattern 的計算，而必須另外區分 direct 與 indirect bilirubin，判斷異常主要發生在產生、處理或排泄的哪一段。

Pattern 的作用，是辨認目前哪一類生化訊號最突出。

它告訴我們，眼前主要呈現的是 hepatocyte injury，還是膽汁形成與流動異常；但它尚未告訴我們，是哪一個疾病造成這種表現。

這裡所說的位置，不是病灶的解剖位置，而是病人在 differential diagnosis 中先落在哪一區。

即使同樣屬於 hepatocellular pattern，AST 與 ALT 的相對關係、aminotransferases 升高的幅度，以及其他檢驗的組合，仍會重新排列疾病的可能性。MASLD、viral hepatitis、DILI 與 ischemic hepatitis 都可能呈現 hepatocellular pattern，卻不會因此成為同一種疾病。

反過來說，同一個疾病也不會永遠停留在同一區。隨著傷害機轉、強度與病程改變，它留下的生化表現也可能改變。

因此，不同疾病可以出現在相似的位置，同一疾病也可以在病程中移動到不同位置。

Pattern 可以縮小範圍，卻不能單獨替疾病命名。

它只先決定病人落在哪一區，不是疾病本身。

但即使知道病人目前在哪一區，仍然少了一個問題：

他正往哪裡移動？

一次抽血呈現的，只是疾病在某個時間點留下的生化狀態。

同樣是 ALT 800，一位病人可能正從正常值快速上升，另一位則可能已經從 5000 迅速下降。兩人在抽血當下具有相同數值，卻處在不同的病程方向。

前者可能表示 injury signal 仍在加劇；後者可能表示造成 injury 的過程已經減弱，或病程已經越過高峰。但只憑 aminotransferases 下降，仍不能判定病人正在改善。

Serial laboratory data 的價值，不只是確認數字有沒有下降，而是把孤立的位置連成病程。

單次檢驗提供位置，連續檢驗才開始顯示方向。

但這條軌跡仍然只描述 injury signal 如何變化。它沒有回答肝臟是否仍能維持合成功能。

這時必須另外打開一條與 injury 平行、卻不能互相取代的判斷軸：

Synthetic function 是否同步改變？

AST 與 ALT 很高，表示 hepatocyte injury 的生化訊號突出，卻不直接等於肝臟已經失去合成能力。相反地，advanced chronic liver disease 的 aminotransferases 可能只有輕度上升，病人卻已經出現 albumin 下降或 PT 延長。

PT 或 INR 對較急性的 synthetic dysfunction 比較敏感，但也會受到 vitamin K deficiency、anticoagulants 與 DIC 影響。Albumin 變化較慢，也可能受到 inflammation、malnutrition、renal loss 與 volume status 干擾。

因此，病程中至少需要同時追蹤兩條不同的軌跡。

一條是 injury trajectory，觀察 hepatocyte injury 的生化訊號正在上升、持續，還是下降。

另一條是 synthetic function trajectory，判斷肝臟維持合成功能的能力是否開始失守。

兩條軌跡可能同向，也可能分離。

Aminotransferases 下降，PT 同時改善，較支持 injury 減弱後，synthetic function 仍然穩定或逐步恢復。

但若 aminotransferases 下降，PT 卻持續延長，便不能把酵素下降直接理解成病人正在好轉。若同時出現 bilirubin 上升或 encephalopathy，則進一步提示排泄功能與臨床狀態也正在惡化。

Bilirubin 與 encephalopathy 不是 synthetic markers，卻是判斷 liver failure 時不能忽略的相鄰訊號。

反過來，劇烈的 aminotransferase elevation 也可以出現在 synthetic function 尚未明顯失守的早期階段。

所以 injury 與 synthetic function 必須並讀，卻不能互相代理。

Injury markers 告訴我們 hepatocyte injury 的生化訊號有多突出；synthetic markers 則讓我們判斷肝臟維持合成功能的能力是否開始下降。

它們都與病情有關，卻不是同一條由輕到重的階梯。

這也帶出最後一個問題：

如果位置不是疾病，辨認位置究竟有什麼用？

Pattern 真正改變的不是答案，而是下一個問題。

當檢驗呈現 hepatocellular pattern，後續評估會轉向造成 hepatocyte injury 的機轉，包括藥物、感染、缺血、代謝與免疫因素。

當 ALP 相對占優勢，問題則轉向膽汁流動與肝內結構。此時 ultrasound、MRCP、CT 或 biopsy 並不是反覆尋找同一件事，而是在不同層次排查不同機轉。

前一項檢查沒有發現異常，只能降低它有能力看見之病變的可能性，不能把所有未被看見的疾病一併排除。

因此，位置的價值，不在於直接提供 diagnosis，而在於決定下一步應該追問哪一個機轉，又該使用哪一類檢查。

這套推理最容易出現的錯誤，是把每一層提供的答案推得太遠。

辨認了 pattern，不代表已經知道 diagnosis。

看見 injury signal 下降，不代表 synthetic function 正在恢復。

影像沒有發現異常，也不代表疾病不存在。

這些都不是檢驗失敗，而是每一種檢驗原本就只回答特定層次的問題。

小麻的 abnormal liver tests 表格，真正建立的不是一份疾病與檢驗值的對照表，而是一套推理順序。

先問目前主要被看見的是哪一個生理環節的異常。

再問 injury signal 正在如何改變，同時沿著另一條不能被取代的軸，判斷 synthetic function 是否同步變化。

最後問，這個位置應該把下一步帶向哪一類機轉與檢查，又不允許我們直接推出什麼。

肝臟檢驗先告訴你，病人目前落在哪一區。

連續檢驗讓你看見，他正往哪裡移動。

而 synthetic function 則讓你判斷，這段移動是否已經開始動搖肝臟維持合成功能的能力。

但這些仍然不是疾病本身。

診斷真正要回答的，仍然是：

他為什麼會在這裡，又是什麼力量正在把他帶向下一個位置。
