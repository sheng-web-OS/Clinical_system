# CPB 術後 HCO₃⁻ 下降：原始研究與圖表

[返回第三篇：離開 CPB 後的酸鹼變化](lessons/2026-10-29-cticu-abg-03-cpb-acidbase.md)

本篇比較兩種不同性質的真實證據：**55 人的群體時序**和**一名特殊腎小管疾病患者的個人病程**。兩者不能合成同一名病人的數據，也不能用兩者的觀察結果證明某一類輸液具有治療效果。

## 2013 年 Chuah 等人：CABG 群體與原始 Table 3

[出版社全文及原表](https://link.springer.com/article/10.1186/1749-8090-8-184)；[Table 3 原始表格](https://link.springer.com/article/10.1186/1749-8090-8-184/tables/3)。原始 PDF 的 Table 2–3、Figures 1–3 及 Appendix I 已依頁面影像核對；Table 3 是 **55 名 on-pump CABG 患者的三時點群體平均**，不是一名患者的完整 ABG，也沒有直接測量 lactate 或 albumin。

原作者計算的是 **SID = Na⁺ + K⁺ − Cl⁻**，不是包含 Ca²⁺、Mg²⁺ 和 lactate 的完整 apparent SID。原圖的不同曲線可能顯示強離子構成、BE、pH 相關變化並非同步；本站圖 1 以三欄獨立單位重新呈現 Table 3 數值，不重製作者的 Figure 1–3。原文使用的 CPB prime 包含 Hartmann’s、mannitol、bicarbonate 與 heparin，**不能把這項研究簡化成「純 normal saline 引起酸中毒」**。白蛋白稀釋可能抵銷酸化是生理學解釋，但作者沒有直接量到白蛋白，且 Hb 相關分析有記載不一致，無法支持個體中介因果結論。

## 2024 年 Protos 等人：另一位真實 CABG 病人

[病例全文與 Table 2](https://pmc.ncbi.nlm.nih.gov/articles/PMC11045673/)。62 歲 Bartter syndrome 男性，CABG 後立即的 Table 2 提供 pH 7.25、HCO₃⁻ 14.5、lactate 12.2、Cl⁻ 94；隔天早上為 pH 7.37、HCO₃⁻ 24、lactate 2.7、Cl⁻ 111。病例討論文字與 Table 2 的「立即術後」pH／lactate 數字不一致；教材採明確標時點的 Table 2，沒有替作者推定兩筆取樣的真實關係。病例是一名有特殊腎小管病的患者，不能當作一般 CABG 後代謝異常的發生率或輸液療效證明。

## 其他機轉與治療證據

- [Hayhoe 等人 1999 年生理研究摘要](https://pubmed.ncbi.nlm.nih.gov/10470571/)：10 名 CABG 患者，使用特定 polygeline prime，Cl⁻ 上升但 lactate 平均趨勢未隨之上升；本次未取得可目視的原始全文圖表，不把它視為所有現代 CPB prime 的代表。
- [Guarnieri 等人 2026 年觀察研究摘要](https://pubmed.ncbi.nlm.nih.gov/41130846/)：50 名成人 CPB 患者的 SIG 與 alactic BE；術後未測陰離子的貢獻不等於每名病人的致酸種類已確診。**公開摘要沒有術後第一天 SIG 的數值與統計比較**；不能從 pH 正常化推定 SIG 已消退，也不能把 ICU 到院時的 SIG 升高外推為持續到隔天。
- [2024 EACTS/EACTAIC/EBCP 成人 CPB 指引](https://pmc.ncbi.nlm.nih.gov/articles/PMC11826095/)§10.3：不同 priming fluid 的生理影響與小型試驗，不足以推論特定 prime 可改善所有主要臨床結局。
- [2008 年 balanced priming fluid 隨機研究摘要](https://pubmed.ncbi.nlm.nih.gov/19115651/)：電解質與 strong ion gap 效應不能僅以 chloride 含量預測；摘要證據不等於已核對所有原圖。
- [既有酸鹼教材的 Pocket Medicine 第九版來源與原圖定位](acid-base-sources.md)：Figure 4-1 的 nomogram、AG 與代償表是必要先備，但本文原創群體圖並非 nomogram 原像素的重製。
