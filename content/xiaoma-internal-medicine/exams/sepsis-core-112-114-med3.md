## 112-1 醫學（三）第 33 題｜為什麼 IL-5 不是 Sepsis 主要促發炎訊號？

**官方身分：** 民國 **112 年第 1 次**（2023），醫師（二）醫學（三）第 **33 題**。原題問：哪一種 cytokine 與敗血症的關聯**相對不密切**？

| 選項 | 對應原題的重述 |
| --- | --- |
| A | Interleukin-5（IL-5） |
| B | Interleukin-1（IL-1） |
| C | TNF-α |
| D | Interleukin-6（IL-6） |

**官方答案：A**（考選部標準答案；更正答案頁未對第 33 題改動）。[官方試卷](https://wwwq.moex.gov.tw/exam/wHandExamQandA_File.ashx?c=302&code=112020&q=1&s=11&t=Q)｜[官方答案](https://wwwq.moex.gov.tw/exam/wHandExamQandA_File.ashx?c=302&code=112020&q=1&s=11&t=S)｜[更正答案](https://wwwq.moex.gov.tw/exam/wHandExamQandA_File.ashx?c=302&code=112020&q=1&s=11&t=M)

**為什麼選 A？** Sepsis 的宿主反應牽涉 innate immune activation。TNF-α、IL-1 和 IL-6 是經常被用來說明發炎、內皮反應及急性期反應的關鍵 cytokines；IL-5 與嗜酸性球分化、第二型免疫反應等關係更顯著。題目問的是**相較之下**，不是「IL-5 在感染中完全沒有作用」。

**錯誤的延伸推論：** 知道 IL-6 參與病理生理，**不代表臨床上單獨阻斷 IL-6 就成為所有敗血症的標準療法**。多條免疫與代謝路徑、不同宿主與時間點，使「參與疾病機轉」和「藥物介入改善死亡率」成為兩種不同證據問題。連回 [Sepsis 第四章：PAMP／DAMP → 內皮、凝血與細胞代謝](../../clinical-os/2026-10-27-sepsis-from-infection-to-resuscitation.md)。

**遷移題：** 如果病人有肺炎、IL-6 上升，是否已足以確立 Sepsis-3？不是，仍需要整合感染與急性器官功能障礙，且 cytokine 數值無法替代病人的灌流評估。

## 112-1 醫學（三）第 64 題｜海水傷口、紫紅水泡與休克：感染來源的證據不能忽略

**官方身分：** 民國 **112 年第 1 次**（2023），醫師（二）醫學（三）第 **64 題**。原題：40 歲肝硬化男性，在海邊釣魚被魚刺刺傷，翌日腿部感染伴**紫紅色水泡與休克**，最可能病原體為何？

| 選項 | 對應原題的重述 |
| --- | --- |
| A | Staphylococcus aureus |
| B | Streptococcus pyogenes |
| C | Pseudomonas aeruginosa |
| D | Vibrio vulnificus |

**官方答案：D**（更正答案未涉及第 64 題）。[官方試卷](https://wwwq.moex.gov.tw/exam/wHandExamQandA_File.ashx?c=302&code=112020&q=1&s=11&t=Q)｜[官方答案](https://wwwq.moex.gov.tw/exam/wHandExamQandA_File.ashx?c=302&code=112020&q=1&s=11&t=S)｜[更正答案](https://wwwq.moex.gov.tw/exam/wHandExamQandA_File.ashx?c=302&code=112020&q=1&s=11&t=M)

**為什麼選 D？** 三個資訊一起改變病原體的先驗機率：**海水／海產傷口暴露**、**肝硬化背景**、**快速惡化並出現血性或紫紅水泡與休克**。這組線索非常符合創傷弧菌（Vibrio vulnificus）嚴重軟組織感染與可能的血流感染，具有迅速致命的風險。不是因為「只要有紫紅水泡就一定是 Vibrio」，而是暴露、宿主與病程彼此增強。

**從選菌名走到救命：** 若臨床高度懷疑，必須立即協調適當抗菌藥與外科評估可能需要的清創／source control，不能等待血培證實才處理壞死性感染風險。抗菌藥的實際組合要依當地可用藥、感染科／外科團隊及最新適用建議決定；本題的官方答案並不是特定抗菌藥處方。連回 [Sepsis 第六、七章：感染灶及 Source Control](../../clinical-os/2026-10-27-sepsis-from-infection-to-resuscitation.md)。

**遷移題：** 如果同樣是低血壓與高乳酸，但完全沒有海水暴露或皮膚水泡，能否依這題直接使用「創傷弧菌」診斷？不能，必須重新尋找感染來源及病原體證據。

## 114-1 醫學（三）第 51 題｜哪一種休克的 SVR 方向不同？

**官方身分：** 民國 **114 年第 1 次**（2025），醫師（二）醫學（三）第 **51 題**。原題問四種休克狀況，哪一項的 systemic vascular resistance（SVR）改變方向最不同？

| 選項 | 對應原題的重述 |
| --- | --- |
| A | CT 顯影劑誘發嚴重過敏 |
| B | 病毒性心肌炎引起的休克 |
| C | 重度脊髓傷害引起的神經性休克 |
| D | 金黃色葡萄球菌敗血性休克 |

**官方答案：B**（標準與更正答案均為 B，無該題更正）。[官方試卷](https://wwwq.moex.gov.tw/exam/wHandExamQandA_File.ashx?c=302&code=114020&q=1&s=0103&t=Q)｜[官方答案](https://wwwq.moex.gov.tw/exam/wHandExamQandA_File.ashx?c=302&code=114020&q=1&s=0103&t=S)｜[更正答案](https://wwwq.moex.gov.tw/exam/wHandExamQandA_File.ashx?c=302&code=114020&q=1&s=0103&t=M)

**為什麼選 B？** 顯影劑過敏性休克可因介質釋放造成強烈 vasodilation；神經性休克因交感神經張力喪失而 SVR 下降；敗血性休克多以 vasoplegia 為重要機轉。這三項偏向 **distributive physiology**。病毒性心肌炎引起的心因性休克則以心肌泵送功能下降為主，常有代償性 **SVR 上升**，故方向最不同。

**這題的真正價值：** MAP 大致與 **CO × SVR** 有關。當 SVR 下降，增加前負荷未必能解決血管張力；當心肌不能送出足夠 CO，盲目提高 afterload 也未必能改善器官血流。**混合性休克時 SVR 可以隨病程、發炎和藥物改變，試題的分類是典型機轉比較，不是臨床上永不例外的公式。** 連回 [Sepsis 第八至十一章：Phenotype、Norepinephrine 與 PHR](../../clinical-os/2026-10-27-sepsis-from-infection-to-resuscitation.md)。

**遷移題：** 若 septic shock 患者用 NE 後 MAP 回升，但皮膚仍冷、心超顯示低輸出，你還能將其視為「只有 SVR 低」嗎？不能，需要重新辨認心輸出與混合型休克。

## 113-1 醫學（三）第 48 題｜Sepsis 合併酸中毒，第一個目標是把 pH 調正常嗎？

**官方身分：** 民國 **113 年第 1 次**（2024），醫師（二）醫學（三）第 **48 題**。原題問以下 Sepsis 治療原則哪一項**最不適當**：

| 選項 | 對應原題的重述 |
| --- | --- |
| A | 應及早選擇適當抗菌藥 |
| B | 因 Sepsis 常有酸血症，使用 bicarbonate 把酸鹼平衡拉回來應是首要目標 |
| C | 靜脈輸液是維持器官灌流的可能介入之一 |
| D | 低血壓且適當補液後仍不足，應考慮 vasopressor |

**官方答案：B**（此科目該次無第 48 題更正）。[官方試卷](https://wwwq.moex.gov.tw/exam/wHandExamQandA_File.ashx?c=302&code=113020&q=1&s=11&t=Q)｜[官方答案](https://wwwq.moex.gov.tw/exam/wHandExamQandA_File.ashx?c=302&code=113020&q=1&s=11&t=S)

**為什麼選 B？** 酸血症可能來自低灌流、發炎相關代謝、腎功能障礙與呼吸代償問題，但 **pH 是生理結果，不等於尚未解除的根本感染或循環瓶頸**。核心救治仍是適當抗感染與必要源頭控制、器官氧送達與灌流支持；不能把「先打 bicarbonate 使 pH 變正常」當成所有 Sepsis 病人的首要目標。

**重要的現行指南例外：** SSC 2026 對單純為了改善 hemodynamics 或降低升壓劑需求而治療 sepsis-induced lactic acidemia，建議**不要常規使用 bicarbonate**；但是對 **pH ≤7.2 且合併 AKI（AKIN 第 2–3 期）** 的嚴重代謝性酸血症患者，則有不同的條件性支持建議。這是要不要在特定高風險情境下使用 bicarbonate 的討論，不會把原題選項 B「首要目標」變成正確。[SSC 2026](https://www.sccm.org/clinical-resources/guidelines/guidelines/surviving-sepsis-campaign-international-guidelines-for-management-of-sepsis-and-septic-shock-2026)

**其他選項的條件：** A 成立於適當感染可能性／風險的早期治療，但並非所有疑似感染者都須不加辨別立即給最廣譜；C 的液體要看 fluid responsiveness 與 tolerance，不能固定追量；D 不表示一定要**等補滿 30 mL/kg** 才可使用 NE，極度不穩定時升壓可以與必要補液並行。連回 [Sepsis 第九、十與十五章：補液、NE 與酸血症](../../clinical-os/2026-10-27-sepsis-from-infection-to-resuscitation.md)。

**遷移題：** 若 pH 7.12、AKI stage 3、嚴重休克且 source control 尚未執行，正確方向是只給 bicarbonate 嗎？不是；酸鹼介入可能變得有意義，但不能取代並行的感染源與循環救治。

## 114-1 醫學（三）第 57 題｜感染合併持續休克，什麼時候不要再等檢驗？

**官方身分：** 民國 **114 年第 1 次**（2025），醫師（二）醫學（三）第 **57 題**。原題：65 歲女性曾於生產時大量出血；現在泌尿道感染、意識不清、BP 85/45、HR 125/min、低血鈉，對大量輸液與升壓劑反應差，懷疑 **adrenal crisis**。應如何診治？

| 選項 | 對應原題的重述 |
| --- | --- |
| A | 抽 ACTH/cortisol 後，等結果確診才給 hydrocortisone |
| B | 分早晚抽 ACTH/cortisol，等待結果才治療 |
| C | 若可立即抽 ACTH/cortisol，就先採檢、隨即給 hydrocortisone，不等報告 |
| D | 先做 cosyntropin stimulation test，等結果才給 hydrocortisone |

**官方答案：C**（更正答案未涉及第 57 題）。[官方試卷](https://wwwq.moex.gov.tw/exam/wHandExamQandA_File.ashx?c=302&code=114020&q=1&s=0103&t=Q)｜[官方答案](https://wwwq.moex.gov.tw/exam/wHandExamQandA_File.ashx?c=302&code=114020&q=1&s=0103&t=S)｜[更正答案](https://wwwq.moex.gov.tw/exam/wHandExamQandA_File.ashx?c=302&code=114020&q=1&s=0103&t=M)

**為什麼選 C？** 生產後大量出血可能造成 **Sheehan syndrome（缺血性腦下垂體損傷）**，遺留 ACTH 缺乏與**次發性腎上腺功能不足**。在感染壓力下，所需 cortisol 增加，卻不能適當供應，可能發生低血壓、低血鈉與意識改變。當病人已是高度疑似 adrenal crisis，不適合為了完成 ACTH stimulation test 或等 8 AM 生理時點，延誤立即需要的 stress-dose glucocorticoids。**可以不延誤地抽血就抽；若抽血本身會延誤治療，應先救治。**

**為什麼它屬於 Sepsis 系列？** 病人可能真的有泌尿道感染，**卻不表示目前全部休克都來自 Sepsis 的 vasoplegia**。腎上腺危象可能由感染誘發，與 Sepsis 共存，且需要不同的關鍵介入。此題也要區分兩種同名藥物情境：SSC 2026 對 refractory septic shock 的 hydrocortisone 是**敗血性休克輔助治療**；adrenal crisis 則是缺乏必要 glucocorticoids 的**立即替代治療**，不是同一個診斷或治療理由。連回 [Sepsis 第十三與十五章：休克持續的鑑別和類固醇](../../clinical-os/2026-10-27-sepsis-from-infection-to-resuscitation.md)。

**遷移題：** 如果抽血結果尚未知、病人仍嚴重不穩定而高度疑似 adrenal crisis，是否應為了較完美的診斷準確率而等待？不應。先採可快速取得的關鍵檢體，但不能延誤救命治療。

## 同一套學習架構如何串起五題？

**112-1 Q33** 問宿主免疫反應；**112-1 Q64** 問病原與感染來源；**114-1 Q51** 問休克的血管阻力機轉；**113-1 Q48** 問干預的優先順序與過度治療的限制；**114-1 Q57** 問原先的「Sepsis」假說不再足以解釋病情時，如何辨認不能等待的另一個危急診斷。

回答它們不需要一套隨題號排列的硬背口訣：必須反覆回到**病原／來源→宿主與器官障礙→循環瓶頸→介入與回饋→重新分類**。這也是 [Sepsis 深度主教材](../../clinical-os/2026-10-27-sepsis-from-infection-to-resuscitation.md) 的共同模型。

**來源邊界：** 官方題號與答案已從內部存檔以及考選部平台比對；第 33、64、48、51、57 題在現行所查版本未見題目更正。選項是教學重述，不宣稱逐字原題；官方考試當年正答與今日 2026 SSC 對特殊族群的判斷應區分。整體教材尚處 Draft，未完成正式公開網站與手機版發布 QA。
