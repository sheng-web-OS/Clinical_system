# Clinical_system v5.1 — Agent contract

Default: Lite-first, repository-first. Read README.md, journal/HANDOFF.md, knowledge/catalog.json and relevant pages before editing.

Mission: research, causal reconstruction, editorial production, audit, targeted repair, and Git-backed handoff for medical learning material. Preserve v4.12 Q0–Q3 and Concept/Decision/Evidence/Navigation. Minimize human maintenance before execution cost; never trade away clinical safety.

For each clinical task: establish scope and source provenance; distinguish case facts, guideline recommendations, evidence, inference and unknowns; write a coherent model with prerequisites and decision boundaries; freeze a draft; audit actionable P0–P3 issues; fix smallest impacted sections; validate downstream dependencies; commit and update handoff. Never claim an independent audit unless it occurred in separate context.

New evidence: run cheap mechanism-change detection (MCD); activate hidden-dependency discovery (HDD) for core mechanism reversals or uncertain impact. Do not maintain Full Claim Graph or MIM by default; require blinded T3/T5/T6 evidence before adopting either.

Clinical pages start draft. Publication requires source IDs with actual inspected locators, no open P0/P1, and an audit matching exact file hash. No PHI, fabricated sources, fictional test outcomes or automatic public deployment.

Tools: existing ChatGPT conversation + GitHub connector first; Work for larger cross-tool tasks; Codex for code repair. CI can check structure, not clinical truth. Stop two nonproductive P2/P3 polish loops and log limitations.
