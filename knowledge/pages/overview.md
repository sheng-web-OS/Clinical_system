# Clinical Knowledge OS

The product is **a coherent, versioned knowledge model**, not an archive of separate websites. Git stores source Markdown and evidence; the site renders approved units for sustained reading.

The system begins with the reader's actual problem, reconstructs its causal premises and clinical decisions, and records how new evidence changes dependent conclusions. [Explore Q0–Q3](reasoning.md).

No clinical content is published in this initial foundation. Previous materials must be recovered and verified before import.
