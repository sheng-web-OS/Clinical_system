## 一、頁面實際承載哪兩個問題

1. **Definition / Etiologies** 以 transient global cerebral hypoperfusion 定義 syncope，但同頁額外列出其他 LOC mimics（seizure、hypoglycemia、hypoxia、narcolepsy、psychogenic），且「Neurologic」段落把 vertebrobasilar insufficiency、SAH、TIA／CVA 同列。此處混用「病因位於何器官」與「事件終末機轉」，正是作者文章的起點。
2. **Figure 1-5** 從 suspected syncope 開始，先做 history／physical including orthostatics／12-lead ECG，再按照 **diagnostic / suggestive / negative** 分流；これは事件解釋的證據狀態，不是三種機轉或三個疾病類別。
3. 「diagnostic」示意 orthostatic finding→OH、ECG abnormal rhythm→arrhythmia；「suggestive」包含 situational or prodrome→reflex hypothesis、abnormal neuro exam→neurologic re-evaluation、abnormal heart or ECG／exertional／no prodrome→echo ± exercise test（在相應臨床情境中另評估 PE／aortic disorder）；無明確線索後視需要 ambulatory rhythm observation。
4. **對圖示箭頭的限定**：這是濃縮的 pathway 而非完整 TLOC 章、也不是對所有病人施作 echo、ETT、CTA、EEG 或 CT／MRI 的醫囑。不能直接把 abnormal neurologic examination 視為一類「neurogenic syncope」。圖框「?」尤其不是已完成 diagnosis 的符號。

## 二、原稿可保留的核心知識資產（A）

- **事件（phenomenon）與病理機轉分類（mechanism）分開**：到院首先知道的是疑似 TLOC，不是事先證明全腦低灌流。
- **根源疾病器官 vs 最後造成 LOC 的機轉分開**：自律神經功能障礙可使 orthostatic hypotension 成立，卻不表示每種 neurologic TLOC 都是 syncope。
- **檢查證據距離事件的遠近**：substrate（易感基質）≠ provoked susceptibility（受測條件下再現）≠ spontaneous symptom–physiology correlation（自發症狀同步記錄）。
- **可能性 vs 後果**：未知病因且 high risk，不可因 baseline ECG／血壓恢復正常就視為安全。這不是與診斷分開的加分清單，而是 diagnostic uncertainty 的同時決策軸。

## 三、醫學上需要的補充／防止誤讀（C / D）

| 主張／小麻畫面 | 核對與編輯結論 |
|---|---|
| 「Neurologic ~10%」作為與 cardiovascular 並列病因 | **D**：典型 focal cerebrovascular ischemia 不造成真正 syncope；posterior circulation syndrome 若有 LOC 應合併檢視 focal deficits／其他嚴重病因。神經科來源疾病透過 autonomic failure 造成 OH 是真正的 syncope；seizure 則多為 mimic。不可把 10% 當作當代所有 syncope 臨床群體的定值。 |
| Abnormal neuro exam→EEG, cerebrovascular CT/MRI | **D**：指南不支持無神經學線索的常規 EEG／頭部影像／carotid imaging。若有持續 focal deficit、外傷、seizure 特徵或其他特異臨床理由，才按該病因採取相應檢查；**EEG 與 CT/MRI 不等價，也不應機械地同時開立**。 |
| Orthostatics (+)→OH | **D**：應區分站立下的血壓下降、症狀同步性、是否足以解釋 TLOC，及 OH 與其他心血管危險因素並存。站立測量有診斷價值但單次 abnormal number 不必然建立此次事件完整因果。 |
| ECG / Echo abnormalities | **D**：可找到心律原因或 structural substrate；「有心臟病」≠「此次 event 由心臟病造成」。若有高危提示需當下進一步監測。ECG 的某些節律與發作時狀態本身也可能達到強證據，不必一概降為 substrate。 |
| no prodrome / exertional / family history | **D**：是提示 cardiac risk 的 features，不是單項 rule-in；須分清楚 exertion **during** vs **after**（可能改變機轉），並綜合 ECG、家族史與心臟結構。 |
| Stable TLOC / negative ECG → ambulatory ECG | **D**：需按照 episode recurrence frequency 與 arrhythmic pre-test probability 選擇 Holter、external／implantable loop；不能一律做短程 Holter。沒有捕捉到事件時的正常 ECG 不足以排除 paroxysmal arrhythmia。 |
| POTS / autonomic disorders | **D**：POTS 並不等於 orthostatic hypotension，也不代表每次 postural symptoms 就是 syncope；需把 orthostatic intolerance、presyncope 與真正 TLOC 分開。 |
| 「If CPR or cardioversion required then SCD not syncope」 | **D**：此為原頁的簡化分類／預後提醒，需按心跳停止與復甦事件使用 cardiac arrest、aborted SCD 等術語；不能反向否定任何曾經由短暫腦灌流不足引起的 LOC，重點是嚴重 arrhythmia 的高風險處置。 |
| Mechanism vasovagal = Bezold–Jarisch | **D**：頁面是教學式機轉概括，現代 reflex syncope 的 pathophysiology 不應全部歸約為單一 LV mechanoreceptor/BJR 模型；正文目前沒有犯此錯，維持反射性 vasodepression / cardioinhibition 的機能模型即可。 |
| MAP ∝ CO × SVR | **C**：作為群體層面的簡化推理有價值，但需註明 brain autoregulation、cerebral vascular factors / ICP，且 arterial hypotension 未必能在到院時量到；不要讓公式取代病人當下的時間序列。 |
| Syncope vs seizure | **C**：短暫 myoclonic movements 亦可出現在 syncope；不能用「有抽動」就排除 syncope，也不能用 prodrome 一項完全排除 epilepsy。恢復速度、postictal state、舌咬部位與見證者描述應綜合解讀。 |

## 五、建議原創視覺（不重製 Figure 1-5 的 layout）

將「診斷樹」轉譯為 **三個連續任務 + 一個全程並行的風險軸**，其箭頭代表臨床假設更新，而非固定病因歸屬：

```text
現象：短暫失去意識／反應（尚未完成事件分類）
            │
            ▼
① 事件分類：真實 TLOC？Syncope 或 seizure / mimic？
            │ suspected syncope
            ▼
② 機轉推理：reflex / orthostatic / cardiac
            │
            ▼
③ 因果證據：事件型態 → physiological susceptibility
                        → 症狀–生理同步紀錄
            │
            ▼
    後續評估或可解釋的機轉診斷

║ 並行安全軸：高危線索、嚴重潛在病因、監測／收治急迫性 ║
```

**圖意義：** ① 的病人初始資料是現象而不是結論；② 是 physiological causal pathway 而非器官清單；③ 說明 substrate 與 captured event 的區別；危險度不能從「是否確診」直接推出。本圖不是經臨床驗證的 scoring tool 或完整急診 disposition algorithm。
