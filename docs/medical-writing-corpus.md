# Medical Writing Corpus｜跨系列醫學文章選稿與整併

日期：2026-10-21。狀態：**編輯規格與首批已確認來源清單**，不是文章已全部回收、已評分或已公開。

## 任務邊界

「小麻閱讀」只是醫學文章庫的一個系列。納入作者本人可授權使用的其他醫學筆記、病例導讀、專題整理與由舊稿改寫的網站內容。第三人講義／PPT／書籍只當參考證據，不因出現在雲端硬碟就被當作作者文章或可公開全文。

每個主題（work）有多個作品版本（version）；同一主題亦可有數篇目的不同的文章。**選基底版本**、**挑可移植段落**、**更新醫學證據**、**正式發布**是四件不同的事。

## 作品基準與 AI 編輯授權（2026-10-21 更新）

**舊稿以 Facebook 發布版為準，新稿交由 AI 自主編輯核定。** 兩條路徑的權限不同，但共同服從臨床安全、來源查核與原稿保真。

- **既有已發表文章：**在 Facebook 找到且核實的公開發布全文，是作者認可的正規原稿基準。保留貼文永久連結／識別、發表日期、全文與指紋。ChatGPT 較晚修訂稿、同題網站或 AI 高分稿均保留作其他版本；可用來製作新教材，卻不能取代歷史原作。如果 Facebook 不可讀、只找到轉述或片段，記為待查，不偽造已認可的發布版。
- **此後新寫文章：**作者明確委託 ChatGPT／AI Agent 依 EPQC、相關臨床證據、品質對照及安全性，**自行決定稿件、版本與可否發布**；不須例行要求作者逐篇審核。AI 通過審稿是 `ai_editorially_approved`，不能寫成作者已親自定稿、歷史原創、真人專科同儕審查或閱讀成效已實驗證實。
- **任何時期皆不互相取代：**「作者認可一個版本」是作品身分問題；「現代醫學上可安全教授」是醫學審查問題。已發表原稿可以因時效問題附安全標記或暫緩公開，應另寫可溯源的 AI 新版，不能隱性改寫舊稿。
- **阻斷及人工介入：**重大醫學不確定性、著作權與個資、無法核實的原稿或來源，以及作者明確要求不發布時，AI 必須暫停。其他一般寫作／版本比較由 AI 自行完成，以降低作者日常維護成本。

細節與執行順序見 [內容先行與跨篇知識整合](content-first-knowledge-integration.md)。

## 四階段編輯工作流

### A. 找回與歸屬
以主題、疾病同義詞、系列名稱及文首命題搜尋 ChatGPT 對話、Library、現有儲存庫與已連線檔案。記錄來源 ID / URL / SHA、版本時間與存取限制。只在內容重合有證據時合併版本家族；保留原檔不覆寫。個案資料先檢查去識別化與發布授權。

### B. 回收評分與評論
收錄每項評價的**原話摘要與可回查來源**、評價者（user/AI/external）、時間、對象版本、評價面向與情境。使用者「太淺」「metadata 混雜」「脈絡亂」「互動沒讓理解更快」屬不同面向的負評，不換算成未提供的星數。針對同一版的新舊評論，保留時間、條件與衝突。

### C. 選主幹與優點整併
歷史文章先依可驗證 Facebook 發布版定義原創基準；此後新稿則由 AI 自主核定最佳版本與發布狀態。整合型新教材依完整論述骨架、醫學正確性、推理中介步驟、圖表與證據相連、時間與認知負擔選主幹。對其他版本作 section-level 判定：保留／移入／改寫／淘汰，逐項說明來源與理由。**使用者評分是編輯偏好證據，醫學正確性是獨立不可妥協門檻**；高分舊版的過期建議不能直接繼承。比較必須控制原文文章／互動網站／面試簡報等不同目的，不能用一個總分掩蓋差別。

### D. 交付與回饋
生成可閱讀的 `content/` 正稿與獨立的私人編輯決策紀錄，確認來源、圖片權利、內容安全與臨床查核後才加進 `site/pages.json`。發行前沿用既有 CI/建站器及公開白名單。新評論更新評分記憶，若觸發實質改善再修訂，不因評論一出現就覆寫正稿。

## 優先度與決策記錄

優先整併資料可得、同題多版、具充分使用者評語而且能明顯改善論述脈絡的作品。首批用 ACS 與 Tamponade 做有對照的合成決策，以 HCM 作單篇優質文本的**候選校準樣本**；不得先將主觀偏好當成經人體試驗證實的學習效率。

每件作品最小編輯記錄（Markdown／JSON 都可；沒有增量價值不引入資料庫）：

```yaml
work_id: hcm-definition-physiology
version_id: unknown-until-fingerprinted
source: ChatGPT Library / HCM_從EF回到定義.md
authorship: verify
publication_rights: verify
user_feedback: []  # 保留原話與定位；找不到即空陣列
clinical_review: pending
editorial_role: candidate
decision: unpublished
```

## 完成條件

1. 每篇公開稿可溯回選稿依據與原始來源，查不到的部分明確標示缺口。
2. 版本選擇能解釋「為何不是最新／最高分那一版」，可指出被採納的優質段落。
3. 不把作者評分、AI 自評、醫學審查與真人理解實驗混成同一項指標。
4. 不發布未授權第三人內容、病人辨識資訊、私人來源全文、未核實重要醫學主張。
5. 不為了存評分而建立持續人工維護的大型 metadata 系統；AI 按需回收，長期只保存無法可靠重建的決策與證據索引。
