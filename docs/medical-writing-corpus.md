## 1. 收錄與發布範圍：作品不是所有相關檔案

**核心出版群**：作者的小麻閱讀系列與確屬作者原創、適合公開教育使用的其他醫學筆記文章。優先回收 HCM、ACS、GI／腹瀉、抗生素與感染、輸液、腹水、肝硬化、B 型肝炎，並擴及**利尿劑、排便藥物、胰臟炎、心衰竭、其他心肌病變、TAVR／主動脈瓣狹窄、ASD／PFO**等作者明確提到的文章家族；隨完整寫作脈絡持續發現其他原創醫學文章。這些都是優先**找回**的類別，不代表每個類別已有可核對正稿，更不自動批准公開。

**系列分流**：小麻閱讀、藥物閱讀及其他作者原創醫學文章是**相互關聯但不可強制混併**的作品系列。Octreotide 文章原屬「藥物閱讀系列」，需保留原生系列身分。腎臟與酸鹼、臨床決策文章可列候選；所有新系列均須確認作者意圖、正稿身分、內容及權利。小麻內科國考是可交叉連結的**新教材系列**，不等同既有小麻閱讀完稿，不能藉其課表虛構既存文章。

**不納入此作品集發布與選稿候選**：心臟外科 Orientation、Type A、CABG 等輪訓報告或導讀；顱內動脈瘤報告／文獻翻譯；實習心得、個人學習歷程、個案病歷、報告素材；除非作者未來重新明確指定。DILV／Fontan 與其他實習相關教學網站目前也不因「曾製作」而列入此作品集。現有 Tamponade 教材屬既有 Clinical System 示範／獨立教材，不當作小麻閱讀文章，也不因本文件新增發表決定；**不要移除或改寫既有已發布內容**。

原始教科書、他人 PPT、學校共筆、從 Google Drive 搜到的同主題檔案不等於使用者著作或可公開複製的內容。作為研究參考時仍需來源、引用、版權與隱私核對。

## 3. 評分、喜好與批評的可信度分離

曾有 2026-08-11 左右的**歷史助理作品集排名線索**：DKA／ketone 99、AKI diagnosis 98、抗生素 5/6／HBV DNA timing／fluid responsiveness 97、腹水「同一管判斷兩次」／抗生素 3/6 與 6/6 96、肝硬化首次失代償／感染未證明仍須抗生素 95、HCM 約 94。**目前尚無對應逐項原始評分訊息可直接核對，不能把這些數字標為使用者親評、客觀成效或自動發布門檻。**HCM 亦曾在其他脈絡有 95–96 的助理評價，可能因量規／版本不同；保留衝突，不平均後冒充精確分數。

每條評語記錄原始來源、時間、評分者（user／assistant／third party）、針對哪個版本與評價維度；例如「深度不夠」「metadata 混雜」「脈絡亂」「只加互動卻沒降低理解成本」等批評，記錄為可行動的文字限制，絕不硬轉化成沒有給出的數值評分。

### 編輯量規與選稿決策

**回收優先度不是醫學重要性排名**：先回收使用者明確指認、版本數多且批評／改進記錄足夠的文章，從每篇保全最佳敘事邏輯開始。正式出版時視醫學更新需求與資料完備程度決定順序，不因某些內容較容易找到就忽略利尿劑、藥物閱讀、胰臟炎、HF、心肌病變或 TAVR。


先設**醫學正確性／知識來源／著作權／患者隱私**硬性通過門檻；再就「核心命題與整體脈絡、必要先備、完整中介推理、影像證據連結、臨床轉移、文字密度及閱讀成本」分維度比稿。不同用途（單篇觀念文／專論／網站／國考教材）不可粗糙加權排名。

**不選最高分版本直接複製**：先挑最有力的全局論述骨架，再從其他版本逐段標示（保留／移入／改寫／不採納）與依據，修訂後以獨立新情境測試新稿。即使高分也不能繼承過時或有害臨床建議。

小麻文章應維持可連續閱讀的原創論述，必要時補清楚 clinical decision，不能為了模板化將文章拆成跳接 metadata、問答碎片或大量無助理解的互動元件。

## 4. 最小知識資產與實際產物

只在私人 repository 保留必要持久資訊：作品家族／檔案來源索引、可驗證的評語與版本定位、最重要的淘汰與移植理由、醫學證據與權利／隱私阻擋。全文原稿用 Git 版本或原所在檔案保存，不為了「記憶」強制維護冗長圖譜或手填資料庫。

建議工作流：

1. 從既有對話、Library、已連接可授權來源、Git 歷史按作品家族找齊版本，保存原檔身分與完整性。
2. 回收使用者評論、助理評分，明確標示來源與未回收的缺口。
3. 產出逐版本「主幹／可移植段落／醫學差異」編輯決策，形成候選正稿。
4. 完成醫學查核、圖片權利與隱私檢查，才由候選轉為可發表。
5. 更新 `site/pages.json`，沿用既有 build/CI gate，實際驗證公開頁面、導航、搜尋；未通過就保留私人草稿。

完成定義：不是「檔案全部放進網站」，而是每一篇**經過辨認、選稿、醫學核查與最終正稿化的文章**可供連續閱讀、保留必要回溯依據，同時使用者不必維護額外系統。
