# 教材視覺出版驗收｜圖有來源，不代表圖有教學價值

**2026-10-27 實際失敗案例**：WPW Figure 01 曾以 900px SVG 三欄水平排列。手機只看得見第一欄，須隱性橫向捲動才能閱讀另兩欄；但該文已具有 `represented`、figure id、caption 和 `ai_editorial_review`。這證明現有來源檢查**不足以**作為視覺品質驗收。

## 每張圖須回答的三個獨立問題

1. **認知功能**：指出本圖的唯一教學任務、讀者應從圖中辨認的變因／時間差／分支／比較，以及「刪掉圖後，哪一步推理會更難」。只是把原文改成箭頭或卡片，沒有獨立辨識價值者刪圖。
2. **醫學／證據對照**：對照原刊臨床影像、原表、圖說／註腳與限制；ECG 不可被非寫實的傳導示意取代。優先使用有適當權利基礎的真實公開圖／官方原圖直連；來源、授權和解讀屬獨立驗收。不能以圖示美觀抵免醫學錯誤。
3. **實際手機閱讀**：從文章自然卷動位置直接理解完整比較，不把重要內容隱在左右捲動的寬幅圖、微小字或模糊縮圖裡。真正需水平操作的多欄原始數據必須有明顯操作提示及不失真的窄版文字摘要。

## 可操作的發行判準

- **必要截圖**：對每張新圖或重大改圖，至少以 375px、390px、768px、1280px 實際渲染，另確認 dark theme、長文字換行、圖說和連結可讀。不得僅靠原始 SVG 的 viewBox 或 CSS `overflow:auto` 宣稱可用。
- **P0／阻擋發行**：重要面板被裁切而沒有可見替代、正文結論與圖矛盾、圖誤導處置／診斷、圖將非實測內容冒充 ECG／原始資料、來源授權不明卻公開重製。
- **P1／退回修圖**：讀圖需要先讀完冗長圖說才能知道箭頭意思；大小縮放使有效字體無法閱讀；不同條件／箭頭方向無法區分；圖沒有回答小標題宣稱的問題。
- **合格標準**：讀者不靠圖說能說出圖的主張與關鍵對照；看完圖說能知道證據來源、限制與例外；以新反事實替換一個條件時，不會套用錯誤的臨床結論。
- `figure_gate.py` 的 `represented` 只代表**來源／結構性證據**。AI 自評、CI pass、內容可開啟，**均不等於**已通過手機視覺、醫學同儕或學習成效驗收。未執行的檢查標記「未驗收」，不得寫「已通過」。

## 自動化與人工邊界

- 最小化長期維護：使用現有 `unittest` 為**曾發生的昂貴失敗**加入定點回歸。WPW 及 pre-excited AF 已加防固定寬 SVG 回歸；不能因此宣稱所有舊圖已合格。
- **實際 screenshot acceptance** 屬另一個發行步驟，須留下哪個 URL／commit、viewport、截圖與判定；未留下證據不得聲稱驗收完成。對每張圖重新「AI 自評 95 分」不是驗收。
- 發生 P0 時，建立可追溯的退回／修復紀錄；先修壞掉的圖與讀者路徑，不靠更長的品質契約彌補。原始未改稿件不應受無關大規模架構改版影響。

本合約不要求所有文章畫圖：**無法增加理解、沒有權利基礎或尚無可靠來源的圖，寧可刪除並改用清楚文字／合法原始連結，也不要發布裝飾性假圖。**
