# Master Prompt v5.1｜Editorial Prose Quality Contract（EPQC）

狀態：正式寫作與審稿品質契約（2026-10-21）。適用於 Clinical System 產生、重寫、更新的醫學教育正文。這是品質底線，不是固定文章模板；其有效性與「是否已達人類作者基準」須經具體稿件對照驗證。

## 0. 最高判準：能否建立新的理解，而不只增加資訊

**合格正文必須讓讀者在讀完後，能區分原先混在一起的問題、重建關鍵理由，並在條件改變時更新判斷。**正確名詞、完整分類、充分字數、圖表、互動及引用都不是這項能力的替代品。

規範以已讀的原創文章為品質錨點：
- HCM：完整讀回《Nonobstructive 只回答了一個問題》（2026-07-14；儲存庫 content/xiaoma-reading/originals/2026-07-14-hcm.md）。價值是辨認錯誤的單線敘事、拆出 morphology/etiology、outflow、filling、contraction 等不相同的問題，接回診斷、治療與原教材；不是模仿句型。
- ACS：本次可讀的《理解與臨床判斷》網站摘錄及其病理→缺血→損傷→介入→剩餘問題的共用模型。價值在於以病程和證據角色串起不同章節；本次**未重新逐節盲審全部網站正文**，不能冒稱完整對標驗證。
- 現行新增教材：content/xiaoma-internal-medicine/lessons/2026-10-21-hypoxemia.md 作為系統自己可再審的稿件，不自動升格為品質金標。它包含氧含量、有效換氣、A–a、V/Q、支持策略與試題等充分內容；須另外檢驗單篇範圍、主命題集中度及閱讀負擔。

其他小麻完稿（感染、抗生素、輸液、GI、肝病、藥物等）未取回全文者，暫不宣稱已校準其文字品質。新增作者認可的完整基準稿後才擴充錨點集。歷史原文是「寫作與教學能力標竿」，不是其他主題的醫學事實來源。

## 1. 編輯器要先回答的五個問題

撰文前在內部確立，不強迫印在正文開頭：

1. **核心命題**：本文要修正哪個常見但不完整／錯誤的理解？沒有具體誤解時，本文最值得解決的臨床決策張力是什麼？
2. **概念邊界**：哪些相似概念處在不同定義、功能、病因、時間、量測、風險或決策層級？它們如何連結、何時不能互換？
3. **不可跳過的中介**：從現象到機轉、從檢查到結論、從介入到效果，哪個理由若刪除便必須靠讀者自行腦補？
4. **證據如何改判**：每項重要檢驗、影像、數字或研究，究竟新增哪個資訊、不能證明什麼、與哪些條件一起才成立？
5. **決策與剩餘問題**：現在改變什麼處置或推論？如果改變一個關鍵條件，判斷會如何分岔？原介入成功後尚未解決什麼？

這五項是撰稿時的檢驗問題，**不是五段式或每頁五問模板**。對定義型文章，重點可在分類軸；對治療文章，重點可在 competing risks 與選擇的時機；對病例文章，重點可在時間序列與新資料改變判斷。選擇符合知識本性的論證形態。

## 2. 文字品質七軸：0–4 評閱錨點

每項採同一級距：0＝缺失或顛倒；1＝僅標籤／零散陳述；2＝局部解釋但需讀者自行補核心關係；3＝可獨立連續理解且包含主要界限；4＝將關係、例外、臨床遷移自然整合而無不必要負擔。

| 軸 | 何謂 4 分的可觀察行為 | 常見未達標訊號 |
|---|---|---|
| A. 命題與取捨 | 整篇服務一個清楚而有價值的命題；重要延伸自然從命題產生 | 將所有知道的主題無差別加入 |
| B. 概念解混 | 主動拆開易混淆的定義、測量、機轉、時間、風險或適應症；指出互不蘊含關係 | 把分類清單誤讀成自然史／嚴重度階梯 |
| C. 中介推導 | 需要讀者理解的關鍵箭頭均有足夠理由，且不製造假的單線必然關係 | A→C，省略不可自明的 B |
| D. 證據與決策 | 說明每項資料的資訊增量、適用前提、不能推論之處及其對決策的實際影響 | 檢驗陽性＝確診；某數值＝一律處置 |
| E. 敘事連續性 | 上一段自然留下下一段真正必要的問題，局部深入能回到共同模型 | 每段皆正確卻像獨立摘要、堆砌過多小標 |
| F. 臨床遷移與邊界 | 至少一個有意義的條件改變能展示判斷如何更新；說明治療後剩餘問題（適用時） | 只有固定答案，改一個變因就失效 |
| G. 語言與認知成本 | 用自然、精準、克制的繁體中文；臨床英文術語有理由；資訊密度高而閱讀阻力低 | 無必要官腔、AI 套語、濫用強調、過度清單化、同義反覆 |

**編輯放行暫定門檻**：A–G 每項至少 3 分，平均至少 3.3 分；A、B、C、D 任一重大缺陷必須退回重寫。這是內部審稿篩選規則，**不是統計學證實「不亞於原創文章」的分數**。分數必須附逐段依據與具體待修句段，不得由單次自評直接宣布達標。

## 3. 不可由分數補償的硬性退稿條件

- 醫學事實、臨床適用對象、證據等級、檢查效度或處置急迫性有重大錯誤／未解衝突；不可拿文字流暢或字數抵銷。
- 將病例缺漏補成觀察事實；將模型自編數據、模擬情境、回溯推理說成原始病歷；引文、數值或研究未核對卻標作已核實。
- 關鍵臨床推論缺少中介，或將平行機轉寫成必然序列；把一個檢查、指標或陰性徵象擴大成全病情的結論。
- 原始指南推薦的適用人群、強度、時點或限制被省略到足以誤導臨床行動。
- 正文只剩分類表、考點卡、目錄式條列或泛泛摘要，沒有能連續讀懂的完整論證。
- 資料來源、編輯 metadata、內部工作日誌、個人排程混進正文，以致讀者找不到主線。
- 將必要中介推導藏在互動、摺疊或大量外部連結，導致不操作就無法理解；互動在沒有增量學習價值下成為敘事替代品。

若稿件是有意識的短篇補充、單一藥物卡或查房快速參照，可保留短格式，但**不能將其宣稱為達到完整深度的主教材**。比較只在相同用途、學習目標及可用閱讀時間下進行。

## 4. 編輯行為規則（保持 AI 的構文自由）

- 以段落承載推導；標題只是路標，不能代替段落。表格適合真正多維比較、查核或並列；不把段落切碎成假表格。
- 出現任何術語／公式／門檻／影像前，先讓讀者知道「為何此時需要它」。隨後交代測到什麼、不能代表什麼、受什麼條件影響。
- 不強迫按 Definition→Pathophysiology→Diagnosis→Treatment 的教科書順序；依當篇問題所需重排，最後再接回原始教材的定位。
- 清楚分開「已觀察」「文獻結論」「當代指南推薦」「本次推導」「仍未知」。正文就地保留**會改變判斷**的來源界限；大段書目與查核記錄移到來源頁。
- 文章不是演算法輸出。不能為達到評分每段都重複「因此／換句話說／真正的問題」，也不能照抄作者標題與句型。密度來自關係，而不是堆術語。
- 完整深度不得被「五分鐘理解」或每日固定篇幅裁斷：五分鐘只是一個進入整體模型的入口，正文允許專業深究。可分次閱讀，不能以摘要假裝完成。
- 圖像與互動只在它們比精確文字更能呈現空間、時間、比較或條件變化時採用；沒有圖也能讀懂核心。遵循 learning-experience-contract.md。

## 4A. 重症視角的敘事位置（適用於有急重症後果的主題）

**Clinical OS 的新編／整合教材必須讓重症觀點成為同一因果敘事的內在延伸，不能只是末端「重症補充」清單。** 進入危急狀態時，應在原問題中交代：是哪個生理代償失敗或風險改變，使既有治療前提失效；目前有哪些證據足以開始支持與升級，哪些分類／病因結論可以稍後完成；為何器官支持、監測與治療終點必須隨之改變。這些是驗收的理解關係，不是要求固定文章結構、每篇一定要寫 ICU 或引用 IBCC。

三項要求獨立驗收：**重症臨床內容有無涵蓋**（clinical coverage）、**醫學來源有無核對**（evidence reliability）、**敘事能否建立理解**（pedagogical quality）。後者不能由多一項來源自動成立。保留歷史原創文章的原文及其版本身分；經後續證據整合所生的新教材不得冒稱原始完稿。詳細來源策略與範例見 [小麻 × IBCC 規範](xiaoma-evidence-expansion.md)。

## 4B. 原文—圖表交叉審查：來源必須能反過來修正文章

此審查屬於 EPQC 的**醫學證據與教學品質關卡**，不只在結尾附參考文獻。當文章引用／使用圖表、研究數據、臨床影像、guideline 流程圖，或重要概念只能靠圖說／表格條件正確理解時，Agent 應主動追查並比較：**作者原稿 → 被引用的原始正文 → 原始 Figure／Table／caption／footnote → 必要 supplementary data → 本次因果模型與新教材**。

1. **追查原始來源**：保留作者原稿及其圖像、引用線索與版本身分；確認原研究／指引的版本、頁碼、圖表編號、讀取範圍。優先看完整可取得的正式正文，而非只看摘要、檢索片段、第二手文章或教學簡報。
2. **逐圖核對必要條件**：對真正支撐關鍵主張的圖表，看原頁（不是只讀圖名），核查 title、axis、unit、legend、分母／分組、時間點、threshold、註腳、限制及圖文是否一致。若只取得文字或縮圖，明確說明核查層級，不宣稱已完整視覺驗證；嘗試補取，失敗則限制依賴此圖的結論。
3. **反向修正認知模型**：分辨原稿已正確建立的推論、原稿省略的前提、圖表簡化所隱去的適用條件、原文自身的不一致，以及 AI 額外推論。保留衝突而不是猜哪個符號或數字是筆誤；醫學後果重大時限制發布。
4. **只附有增量價值的材料**：優先呈現真正減少理解負擔的機轉圖、臨床影像、原研究結果與決策分支；在正文就地解釋「為何此處需要這張圖／表、它能證明及不能證明什麼」，讀者可返回原文精確位置。不是每篇都必須有圖，也不是把所有找到的圖塞進網站。
5. **權利與原創界線**：官方可閱讀不等於允許本站重製。無明確合法重製依據時，連結原頁並以可追溯、原創的教學重繪取代；標明 adapted from 或 original teaching diagram，不能用看似原研究的虛構數據／影像。作者原稿保留不覆蓋；新推論進入獨立的 AI 整合教材。
6. **最小審查留痕**：記錄「哪個主張／原稿段落」「哪張圖表及原文位置」「查到了什麼」「有何限制或衝突」「教材新增／修正了什麼」。不強制持久維護全域圖譜、逐句 Claim ID 或獨立管理平台。**沒有取得原文／原圖不能標為已審完；沒有證實圖像可合法重製不能直接嵌入網站。**

已執行的局部範例見 [HCM 原文—圖表交叉審查](../audit/hcm-figure-evidence-check.md)。範例本身也明列未取得的畫面、未驗證材料及後續發布限制。

## 4C. 先備概念與臨床實例：防止高階推理搶跑

適用於有核心治療工具、檢驗或新術語的教材。**在把某工具當作判斷前提以前，必須先教到足夠讓初次接觸者知道「它實際是什麼、如何操作／呈現、改變哪個生理量、又無法解決什麼」**。不能用「定義已出現」取代真正可用的解釋。先備解釋應接在讀者需要它的位置，不必強制各篇使用相同章節順序。

**病例選擇預設以可追溯真實 case report 優先**；若多個病例在核心臨床決策呈現相反結局，可用對照打開問題，但要明確指出當事人的病因、時間線、介入條件、測量變化與報告所缺資料。凡是引用的化驗、影像或數據都要解釋「為何這一項會使判斷不同」，不為熱鬧而搬入與命題無關的細節。真實病例不足時才使用自編情境，清楚標示；生理公式與純數學示意不假裝是臨床病例資料。

**病例不是療效證據的替代品。**單一成功或失敗例不能推翻原本適用族群的 guideline；必須區分觀察、作者推論、選案偏差與反事實練習，特別不得因病例有戲劇性而淡化氣道、循環與延誤救援的風險。原始 case report 若數據互相矛盾，要註明並限制結論，不以合理想像補缺漏。

實作檢查只問兩件事：**「讀者是否在第一次需要此概念時就已充分理解？」與「病例哪個具體轉折真正改變了推理？」**，避免為落實偏好而新增大型模板或常駐維護工作。

## 5. 實際審稿流程：少規則、強驗證

**Draft → adversarial edit → source check → benchmark compare → publish**，能在當次 Agent 工作中完成，不新建常駐服務、持久全文 Claim Graph 或人工維護台帳。

1. **寫作**：模型自主選擇最合適的敘事形式，完成不依賴互動操作的正文主線。
2. **對抗式複讀**：帶著「讀者在哪一段必須自行補完理由？」逐段標出缺失；從全文再查是否偏離核心命題或納入無增量內容。至少測一個反事實轉折，類型隨篇章變化。
3. **來源查核與圖表對讀**：將重要病人資料、臨床門檻、建議、原研究結果與相關原始 Figure／Table／caption／腳註回對合法來源；核查圖與正式推薦文字的適用條件，標明實際查看範圍與未知。對重要因果敘述反向查是否需要補圖或更正，不能將寫作錨點當醫學權威。
4. **錨點對比**：用 HCM 全文的解混／推導與 ACS 的病程／證據共用模型，判斷新稿**是否具備同等的認知動作**，而非是否寫得一樣；按七軸給有根據的分數。對高影響教材、新版模型或品質疑慮，使用與撰稿分離的審稿脈絡及去識別稿件的雙向比較，保留具體差距。
5. **修訂並回查**：集中補缺少的中介、刪與命題無關的內容，再測評。同一重大缺陷反覆出現時，先分析編輯策略是否失效，不立即增加永久性的逐條提示規則。
6. **發布**：只有在來源、安全與語義門檻通過後才能發布。正式公開作品的 review status 要反映真實審查，不能由自評代替獨立醫師同儕審查或使用者測試。

**品質評定紀錄最小欄位**：稿件與版本、比較錨點、七軸分數及理由、硬性問題／修訂處、來源核查範圍、是否經獨立審稿、結果（pass/revise/hold）。不要求每篇持久保留全套推理過程；只保留有追溯或再發風險價值的判斷。

## 6. 三組反例：測試是否真的理解這份契約

**HCM 題**：若一篇稿件只寫「EF 正常、無 LVOTO，但仍可能 HF」，仍不及格；必須能解釋 EF 是排出比例、EDV 與 stroke volume 的差異、filling pressure 的代價、以及為何 nonobstructive 不排除 filling failure。也不能把所有 HCM 病人寫成必經相同病程。

**ACS 題**：若一篇稿件單列 ECG、troponin、PCI、DAPT 而沒有交代缺血／損傷訊號的不同時間、介入改變哪個環節、治療後還留下什麼，仍不及格。即使補充大量指南數字，也未必形成更好的文章。

**氧合／換氣題**：若只寫「SpO₂ 正常不代表通氣充分」，仍不及格；須能說明補氧改善氧合卻未改善有效肺泡換氣時 PaCO₂ 為何仍上升，並避免把同一問題擴張成沒有明確主次的所有胸腔醫學。

反過來，篇章若主題本質是藥物比較或研究證據，不能強求它套入這三組心肺機轉。測試應要求**相同深度的認知推進**，而不是相同段落順序或章節數。

目前完成的是**品質標準建置**，不是非劣效實證。待完成：
- 選取數篇作者已認可、主題與類型相近的完整完稿作錨點；保留原文，不以 AI 改寫版本取代。
- 用相同題材、相同原始證據與相近閱讀負擔，製作不同策略的正文；由不知作者來源的評審比較概念解混、機轉重建、反事實應用、錯誤率與認知負擔。可用獨立 Agent 作先篩，不能把它當成人類讀者的替代實證。
- 預先定義「重要理解遺失／錯誤」為不可接受；在正確性不退步的前提，分析是否更少時間完成相同理解，及是否增加新的自主推論能力。
- 若失敗，回到失敗段落與工作策略修正；**不得因模型版本較新就聲稱已更好**，亦不可為提高分數而放寬門檻。

## 8. 與其他契約的職責邊界

- master-prompt-v5.1-architecture.md：保存最小必要知識資產、原生 Agent 能力與自我修正的系統原則。
- **本契約（EPQC）**：正文的概念解混、中介推導、證據—決策連結、敘事與語言品質。
- learning-experience-contract.md（LEC）：多層閱讀與互動是否真正降低理解負擔；網站介面不可掩蓋正文不足。
- xiaoma-depth-standard.md：小麻國考的專屬補充（Pocket／IBCC／官方國考與版面分工），不降低本契約通用底線。

**最終標準：好文章不是讓 AI 展示自己知道多少，而是使讀者在沒有作者陪同時，也能自行走完必要的推理。**
