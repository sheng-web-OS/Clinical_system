# Conversation-first operating protocol

1. Recover actual Git state, AGENTS.md, handoff, catalog and source registry; do not substitute remembered plans for committed artifacts.
2. Scope the user's question and prerequisites. Retrieve original medical sources and precise versions/locators. Distinguish evidence from interpretation.
3. Draft Q0 situation, Q1 mechanism, Q2 conditional clinical decision, Q3 reassessment/transfer. Use Concept/Decision/Evidence/Navigation throughout.
4. Freeze draft; independently audit when a genuinely separate context is available. Log P0–P3 findings with affected text, cause and acceptance test.
5. Repair locally; inspect dependent units and actual diff. Block publication of unresolved P0/P1 clinical material.
6. Update knowledge/pages, catalog, evidence, audit and one-screen handoff; run tests; commit. Check actual CI result before reporting success.

**New evidence:** local claim change → targeted recheck. Core mechanism change or unknown blast radius → MCD triggers HDD causal reconstruction across units. Full persistent graph only after experimental incremental benefit.

**Execution limits:** GitHub connector permissions and current session are required for writes. There is no always-on Agent. GitHub Actions performs post-commit static checks; not a clinical expert review. Work and Codex are optional escalation environments.
