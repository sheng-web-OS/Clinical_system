# Master Prompt v5.1 — Learning Experience Contract (LEC)

版本：2026-10-21｜狀態：正式預設設計契約；成效尚待實驗驗證。

## 1. 目標與邊界

**預設提供「約 5 分鐘核心理解 → 按需深入臨床推理 → 原始證據與專業深究」的單一連續知識體驗。**五分鐘是設計目標，不是證明已達成的宣稱，也不是截斷必要安全資訊的硬性時限。

這是一套醫學知識與教材編輯系統的出版契約，不是只針對 cardiac tamponade、ACS 或任何單一網站的模板；不強迫每一個主題使用相同元件。AI 應先推理最有效的教學結構，再選擇文字、真實影像、互動或比較。

## 2. 三層共用同一知識模型

1. **核心理解（目標約五分鐘）**：一個可在一屏到少數連續視野中定位的整體模型，清楚呈現臨床問題、主要機轉、關鍵證據、決策分岔、不可忽略的邊界；避免先堆分類與文獻。
2. **臨床推理**：透過原病例的時間轉折與反事實變因，說清楚「新資訊改變哪個判斷、為什麼、什麼沒有改變」；先備知識就地補充。
3. **專業深究**：就地展開可核查的 guideline、原研究、原始圖片／合法來源連結、適用條件、證據等級、爭議與失效情境。返回時仍保留原來推理位置。

三層**不應是三套重複文章**。每個核心節點與深入說明共享相同的因果命題與來源；出處和例外條件不得因濃縮而消失。

## 3. 有用互動的最低條件

- 互動應降低理解所需的跨段整合、工作記憶負擔或反事實推理成本；不能把目錄、搜尋、字體、明暗切換當作教學互動。
- 操作一項關鍵變因後，必須可見**模型狀態、證據解釋或處置判斷**如何變化，並說明不變部分與推論界限。
- 圖與文字同時回答同一問題；若靜態圖或短文足以達到更好的效果，**不增加互動**。
- 互動不能暗示虛構病例數據、確定性的臨床規則或模型未經證實的預測；對高風險或不確定情境明示限制。
- 互動需要基本鍵盤操作、可讀文字後備與行動裝置版面；無 JavaScript 時仍可接觸核心知識。

## 4. 稿件最低交付與驗收

對每個新增教材，編輯 Agent 應生成：

- 一個可以單獨理解的核心主線，能回答「在解決什麼／主要機轉／什麼證據改判／接下來如何處理／界限在哪」。
- 核心→臨床推理→證據的就地深入連結，以及可回到核心位置的路徑。
- 至少一個會改變判斷的反事實檢驗；若主題不適合互動，應明確選用靜態呈現，毋須為了符合形式強行添加控件。
- 對每個可操作的決策分岔標示資訊來源、假設、重要例外及未被解決的問題。
- 發布前通過現有的醫學證據、來源、檔案鏈結及無虛構數據檢查；不因追求短而放寬。

## 5. 成效驗證：先導實驗，不先增加平台規則

**先導主題：Tamponade。**同一證據與同一教學目標製成 A（高品質非互動敘事）與 B（核心模型＋有意義互動）兩版；ACS 既有課程網站與原講師 PPT 可作架構參考，但不作 Tamponade 成效的直接對照。

建議以交叉或平衡分組、等難度但不同題目，控制先後順序與重測記憶效應。測量：

| 指標 | 評價方式 |
|---|---|
| 理解時間 | 到達預先定義之合格理解門檻所需時間，並記錄未在時限內達標者 |
| 核心機轉掌握 | 用新情境解釋因果鏈與各檢查的證據角色，採盲式量規評閱 |
| 遷移能力 | 改變循環狀態、影像條件或共病後，能否更新決策而非背答案 |
| 關鍵安全錯誤 | 是否將 effusion 等同 tamponade、以單一陰性 echo 徵象排除、延誤不穩定病人必要評估等 |
| 認知負擔及操作成本 | 簡短負擔評分、操作次數、回頭查找及迷失節點 |
| 製作維護成本 | Agent 產製時間、人工介入次數／耗時、改版成本 |

**預設升級判準（試驗前可預註冊調整）：** B 的核心／遷移正確性不能低於 A，不能增加重大安全錯誤；在這些條件下，若 B 的合格理解時間中位數比 A 低至少 20%，才宣稱取得初步效率增益。小樣本只供篩選，不代表完成統計證實；應另以新使用者／新主題重測。若不能通過，先分析內容脈絡，再判定是否需要互動，而非增加控件。

## 6. 對 Agent 與長期系統的要求

- **最先優化學習成果與讀者理解成本，才是頁面功能數。**
- AI 自主決定每篇文章的最佳認知路徑和互動形式；長期保存通用的品質契約、不可可靠重建的專家脈絡及盲測案例，不累積主題專用的僵硬腳本。
- 避免永久維護每個互動節點的全域狀態系統，除非對照測試證明帶來必要可靠性提升。
- 明確區分「已寫入規格／已產出原型／已部署／已通過學習效率實驗」。目前只有規格成立，Tamponade 網站仍以靜態閱讀為主，尚未完成 LEC 的實證驗收。
