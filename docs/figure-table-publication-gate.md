# Figure／Table 回收完整性：出版硬性門檻

適用：site/pages.json 中新發布或修訂的教學正文（現行識別：/lessons/ 或 kind=ai_integrated）。來源頁、系列索引、未經改動的歷史原稿，不當作新稿。執行路徑：site/catalog.py → site/figure_gate.py；網站建置與 unit tests 使用同一規則。

## 出版前必須回答

1. **原頁是否真的查過？** 依《Pocket Medicine》第九版原 PDF 及必要 guideline／original article，核對每張重要 Figure、Table、caption、footnote、版次與頁碼；單靠抽字／搜尋片段不能宣稱已核對原圖。
2. **圖表如何改變理解或判斷？** 辨認其提供的分類軸、因果關係、時間差、決策分支及適用界線，選最小但足夠的正文安置位置。
3. **公開閱讀介面有沒有相應證據？** 可依授權嵌入原圖；未確認授權時，在正文放獨立重繪的教學圖並標明不是原書原圖，或提供可開啟的官方原表／原圖直接連結和解讀。不允許只給裝飾圖或無關來源。
4. **是否把來源審查與其他驗證分開？** 正文可讀、CI 通過，不等於醫師獨立同儕審查、圖像授權認證或真人學習測試通過。

## 三種狀態及系統行為

- represented：重要的原圖／原表已找到，每一項有來源頁、原書定位、正文圖解（有錨點及來源圖說）或原始圖表可直接開啟的網址，以及教學意義和界線。允許通過機器結構檢查。
- no_relevant_visual：原頁已查且沒有對此文產生重要理解差異的圖表；必須提供查閱頁次、證據來源頁可核對的字句和充分理由。允許通過機器結構檢查，但這是有條件的編輯聲明，不是機器證明「原書沒有圖」。
- pending／未建立記錄：已知有重要圖表未補、尚未讀到原頁、缺授權／可用呈現或來源無法核對。**新稿不得進出版白名單，建置失敗。**

## 實際執行

- 私有機讀清單：audit/figure-gate.json。機器執行器：site/figure_gate.py，由 site/catalog.py 的 load_pages 啟動，因此 unit tests 和 tools/build_site.sh 的正式建置都會檢查。
- 重要圖表 item 要有：原書頁碼及圖／表身分、可在公開來源頁找到的文字定位、為什麼此圖能改變推理、適用條件、正文對應圖（需真實 figure id 與 figcaption）或原始圖表 URL。來源頁必須在 site/pages.json 公開發布，文章必須有能點到來源頁的連結。
- 圖片授權、原圖完整像素核對、醫學事實與教學效果屬另外的人工或獨立審查；本 gate 只驗證留下可追蹤的承諾和相應輸出，不能自行判定是否漏了某張尚未被辨識的圖。

## 舊文轉入門檻的過渡

啟用本規範時現存十篇尚未做完整圖表回收驗收的教學正文，列在 legacy_frozen，使用各篇既有 Git blob SHA 固定原版本。**不是宣稱已查核通過**。它們保持公開可讀；一旦內容變動就會觸發 LEGACY_CHANGED 並拒絕發布，除非補齊完整 reviews 記錄、移出凍結清單。不得只重設 fingerprint 來假裝完成。

利尿劑整合版是首件通過新門檻的案例：小麻 PDF 第 179 頁為 sigmoid 曲線的文字敘述；第 180 頁才有 Approach to Diuresis 原書五步驟表。網站 Figure 01／02 是獨立繪製的教學圖，不是翻拍原書。其來源頁為 content/xiaoma-reading/diuretics-sources.md。

**決策核心：** 缺圖不是所有文章都得補幾張圖；真正的出版失敗，是正文需要原圖的決策訊息，卻沒有在讀者可以看到的位置留存，也沒有任何可追溯定位。
