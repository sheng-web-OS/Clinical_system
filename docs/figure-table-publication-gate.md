# Figure／Table 回收完整性：出版硬性門檻

適用：site/pages.json 中新發布或修訂的教學正文（現行識別：/lessons/ 或 kind=ai_integrated）。來源頁、系列索引、未經改動的歷史原稿，不當作新稿。執行路徑：site/catalog.py → site/figure_gate.py；網站建置與 unit tests 使用同一規則。


> **視覺驗收不是來源驗收**：本 gate 不能偵測手機上被裁切的寬圖、縮小到不可讀的原始 ECG 或缺乏教學功能的示意圖。必須另按 [教材視覺出版驗收](mobile-figure-quality-contract.md) 留下實際手機／桌面 render 和醫學判讀；`represented` 或 `ai_editorial_review` 不代表視覺通過。

## 出版前必須回答

1. **原頁是否真的查過？** 依《Pocket Medicine》第九版原 PDF 及必要 guideline／original article，核對每張重要 Figure、Table、caption、footnote、版次與頁碼；單靠抽字／搜尋片段不能宣稱已核對原圖。
2. **圖表如何改變理解或判斷？** 辨認其提供的分類軸、因果關係、時間差、決策分支及適用界線，選最小但足夠的正文安置位置。
3. **公開閱讀介面有沒有相應證據？** 原書 Figure／Table 必須先完成私下逐圖核讀及其教學用途審查；公網依**逐圖合理引用風險**決定採必要短幅引用、經授權引用、合法原始來源連結，或另創具實質教學意義的非臨摹示意圖。必須標明原圖「已私下核對／已公開重製／僅提供來源定位」各自不同狀態。不得將原創圖冒稱為原圖，也不得只以無關裝飾圖代替決策資訊。
4. **是否把來源審查與其他驗證分開？** 正文可讀、CI 通過，不等於醫師獨立同儕審查、圖像授權認證或真人學習測試通過。

## 小麻原圖優先（2026-10-26 使用者修訂）

**在 Pocket Medicine 找到與當前推理直接相關的原圖／原表，就以原圖作「研究與編輯階段」的逐欄對讀基底；公開呈現採原創解析為主、必要原圖合理引用為輔。** 原圖保留標題、欄位／座標、圖例、caption、footnote 及必要相鄰條件；正文要帶讀者辨認分支與限制，而不是只把圖片貼上。清楚標示版次與 reader PDF 頁碼；**只有當原像素實際於公網重製且通過權利評估時**，才提供清晰圖片及原尺寸放大入口並目視檢查手機呈現。未公開原像素時，須讓讀者知道合法取得原書的來源與原圖定位。

AI 原創圖可以補原書未展開的因果中介、時間序列或病例比較；**公開版可以在不重製原圖時使用原創圖作教學主體**，但必須標示「原創示意、非原書圖」，並在來源頁留下已核原表之定位、關鍵分支與不能重現的限制。原圖已私下核對不等於公開版本已有原圖；其他指南的圖也不能冒充小麻原圖。原書已過時或有簡化／疑義時，原像素不暗改，在旁逐項對照現行來源並明示不能沿用的分支／劑量。

原圖存在、已讀、已擷取、已合法公開是不同狀態。若原圖公開重製風險尚無法合理接受，先保留私人原圖與對讀紀錄，公開版採原創解析並連結出版社官方合法取得入口；**只對原圖的公網重製記為 HOLD，不自動阻擋整篇原創教材**。未完成原圖核讀、重要表格被錯誤轉寫、來源無法識別、或醫學硬性錯誤時，整篇仍 HOLD。使用者提供書檔或要求使用原圖，不自動等同已取得出版社的公開重製授權。這不要求撤除既有未改稿件，但必須如實列出其原圖待補，不能宣稱已符合本次新要求。

以下機器 `represented` 僅是結構性證據，不自動證明已完成上述原圖優先、像素保真、權利或醫學對讀驗收。

## 公開圖像引用的法律判準（2026-10-26 決議）

依台灣著作權法第 52、64、65 條，及智慧財產局相關說明：教學、評論、研究有必要時可以在合理範圍內引用公開發表的圖像／表格，並標明出處；**署名本身不等於合理使用，無法保證個案合法**。對每一張考慮公開重製的第三方圖，留下：①使用目的與公開、營利狀態；②作品原創性與圖像性質；③全圖／局部、精華比例及其必要性；④對原著授權市場的替代效果；⑤可否以原創圖＋定位／連結完成同一教學目標；⑥決策 `authorized`、`fair_use_assessed`、`link_or_original_only` 或 `hold` 與審查時間。不得以自動程式標記 `fair_use_assessed` 充當法院或出版社的合法性保證。這是出版風險治理，不是法律意見。

合法資訊定位：[全國法規資料庫《著作權法》](https://law.moj.gov.tw/LawClass/LawAll.aspx?PCode=J0070017)；[智慧財產局：研究時引用圖表與市場替代](https://www.tipo.gov.tw/tw/tipo1/209-21680.html)；[智慧財產局第 52 條彩圖引用函釋](https://www.tipo.gov.tw/tw/copyright/692-15208.html)。

## 三種狀態及系統行為

- represented：重要的原圖／原表已私下核對，每一項有來源頁、原書定位、正文**原創**圖解（有錨點及來源圖說）或合法可開啟的原始圖表 URL，以及教學意義和界線；有著作權風險評估紀錄。允許通過機器結構檢查，**不代表原圖已公開，也不代表合法性已獲最終確認**。
- no_relevant_visual：原頁已查且沒有對此文產生重要理解差異的圖表；必須提供查閱頁次、證據來源頁可核對的字句和充分理由。允許通過機器結構檢查，但這是有條件的編輯聲明，不是機器證明「原書沒有圖」。
- pending／未建立記錄：重要原圖／相關原表尚未核對，或沒有合法且有教學價值的公網呈現方式，或來源無法核對。**新稿不得進出版白名單，建置失敗。** 僅缺出版社原像素重製授權、但已完成原圖核對且有原創解析及合法連結者，不必自動 HOLD 整篇。

## 實際執行

- 私有機讀清單：audit/figure-gate.json。機器執行器：site/figure_gate.py，由 site/catalog.py 的 load_pages 啟動，因此 unit tests 和 tools/build_site.sh 的正式建置都會檢查。
- 重要圖表 item 要有：原書頁碼及圖／表身分、可在公開來源頁找到的文字定位、為什麼此圖能改變推理、適用條件、正文對應圖（需真實 figure id 與 figcaption）或原始圖表 URL。來源頁必須在 site/pages.json 公開發布，文章必須有能點到來源頁的連結。
- 圖片授權、原圖完整像素核對、醫學事實與教學效果屬另外的人工或獨立審查；本 gate 只驗證留下可追蹤的承諾和相應輸出，不能自行判定是否漏了某張尚未被辨識的圖。

## 舊文轉入門檻的過渡

啟用本規範時現存十篇尚未做完整圖表回收驗收的教學正文，列在 legacy_frozen，使用各篇既有 Git blob SHA 固定原版本。**不是宣稱已查核通過**。它們保持公開可讀；一旦內容變動就會觸發 LEGACY_CHANGED 並拒絕發布，除非補齊完整 reviews 記錄、移出凍結清單。不得只重設 fingerprint 來假裝完成。

利尿劑整合版是首件通過新門檻的案例：小麻 PDF 第 179 頁為 sigmoid 曲線的文字敘述；第 180 頁才有 Approach to Diuresis 原書五步驟表。網站 Figure 01／02 是獨立繪製的教學圖，不是翻拍原書。其來源頁為 content/xiaoma-reading/diuretics-sources.md。

**決策核心：** 缺圖不是所有文章都得補幾張圖；真正的出版失敗，是正文需要原圖的決策訊息，卻沒有在讀者可以看到的位置留存，也沒有任何可追溯定位。
