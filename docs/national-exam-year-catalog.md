# 醫師國考題編目與發布規約

## 唯一身分，不得以撰文日期取代考試年度

每題採 `(exam.year_roc, exam.sitting, exam.stage, exam.subject, question_number)` 作為唯一鍵。例如：
`(108, 1, 2, "醫學（三）", 25)` 代表民國 108 年／西元 2019 年、第一次考試、醫師第二階段、醫學（三）第 25 題。

`date` 只表示教材文章發布或修訂日期；不代表原始試題的考試年度。題目可能由一篇跨題號的完整文章詳解，該篇以 `exam.question_numbers` 指向實際收錄的每一題。

## 網站閱讀流程

[小麻內科國考首頁](../content/xiaoma-internal-medicine/index.md) → 「歷屆國考題／按照考試年度」 → [歷屆國考目錄](../content/xiaoma-internal-medicine/exams/index.md) → 年份 → 第幾次 → 第幾階段 → 科目／試卷 → 題號直接錨點。

目前已確認的 108 年第一次醫師第二階段醫學（三）共十二題，分成心臟與兩篇腎臟詳解。網址沿用既有三個公開頁，題號新增固定 `#q-題號` 錨點；原有章節 `#part-n` 不刪除。

`site/exam_archive.py` 從 `site/pages.json` 自動渲染目錄與首頁年度卡，按民國年度由新到舊排序，不因將來增加 109、110 年而需要人工修改首頁。對題號重複、年度不合格式、考次／階段缺漏、科目缺失，建置應立即報錯。

## 分類邊界

- **官方歷屆真題：** 核對考選部來源後才設定 `exam` metadata，才會出現在依年度編排的專用目錄。
- **自編練習、跨題型教學、疾病概念文章：** 保留原有題目或文章內容，但不應冒充某年度的官方試題。可透過主題閱讀與搜尋查找。
- **官方原題與現行醫學知識：** 年份身分永不改變。即使後來指引更新，應註明「原年官方答案」與「今日臨床判斷」的差異，而非改寫原始考試身分。
- **來源與 QA：** 結構測試、原始試卷核對、Figure／Table 驗收與獨立醫師審查是不同門檻；所有已存在的門檻繼續保留。

後續若需要針對單題建立獨立詳解，先核對唯一鍵與現有跨題文章，避免同年度、同試卷、同題號在網站同時存在兩個互相矛盾的正式版本。
