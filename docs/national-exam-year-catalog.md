# 醫師國考題編目與發布規約

## 唯一身分，不得以撰文日期取代考試年度

每題採 `(exam.year_roc, exam.sitting, exam.stage, exam.subject, question_number)` 作為唯一鍵。例如：
`(108, 1, 2, "醫學（三）", 25)` 代表民國 108 年／西元 2019 年、第一次考試、醫師第二階段、醫學（三）第 25 題。

`date` 只表示教材文章發布或修訂日期；不代表原始試題的考試年度。題目可能由一篇跨題號的完整文章詳解，該篇以 `exam.question_numbers` 指向實際收錄的每一題。

## 網站閱讀流程

[小麻內科國考首頁](../content/xiaoma-internal-medicine/index.md) → 「歷屆國考題／按照考試年度」 → [歷屆國考目錄](../content/xiaoma-internal-medicine/exams/index.md) → 年份 → 第幾次 → 第幾階段 → 科目／試卷 → 題號直接錨點。

獨立或跨題詳解沿用既有公開頁及 `#q-題號` 錨點，原有章節 `#part-n` 不刪除。收錄數量直接由出版目錄計算，不在規格或測試中硬寫最新總數。

`site/exam_archive.py` 從 `site/pages.json` 自動渲染目錄與首頁年度卡，按民國年度由新到舊排序，不因將來增加 109、110 年而需要人工修改首頁。對題號重複、年度不合格式、考次／階段缺漏、科目缺失，建置應立即報錯。

## 文章與真題的雙向連結

只在既有 `site/pages.json` 維護關係；不新增題庫、另一份答案或主題登記檔。

年度目錄按每份試卷的實際題號逐列排序，預設只顯示題號與短考點；**只有確實另有獨立的概念教材時，才顯示收合的「教材」入口**。題號本身會開啟該題完整詳解，因此該題所在文章及該題庫的另一個章節不得重複列為「教材」；另一本題庫也不是額外的概念教材。沒有適合的其他教材就不顯示此按鈕，不影響題目與答案的可讀性。隨文題目的短考點填在 `exam_questions.topic`；舊式單卷詳解填 `exam_topics`（題號字串對短標籤）。這些是顯示標籤，不改變正式題目、答案或身分。

- **既有獨立詳解**：維持 `exam` 欄位。
- **概念文章已包含正式真題**：在該文章加入 `exam_questions`。每筆包含 `year_roc`、`sitting`、`stage`、`subject`、`question_number` 與精確的 `question_heading`。可用 `concept_heading` 指定同篇應回讀的二級標題，`focus` 描述考點。由建置器產生含完整考試身分的穩定錨點，避免不同年份的同題號互撞；文章仍保留概念教材身分與既有章節。
- **文章連到別處已發布的真題**：在 `related_exams` 中填同一組五欄身分、`focus` 與可選的 `concept_heading`。年份頁和真題頁的反向連結由這一筆自動生成；同一題可以對應多篇文章，但每篇只登記一次。
- **隨文練習已重複列出某道題**：`related_exams.question_heading` 指向本頁現有題目標題，只加原詳解與年度入口，不重複嵌入，也不產生第二個官方題目身分。

文章末尾的「相關國考題」直接取用正式詳解頁已編譯的對題內容，預設收起；原詳解頁的答案展開方式與來源連結保留。重用的 SVG／MathML ID、圖說引用與本頁片段連結會重新定域，指向其他章節的片段則回到正式詳解頁。歷史作者原稿的來源 bytes 與指紋不改動，補充題目放在原稿之外。

建置驗證完整題目身分、發布白名單、精確題目標題及概念二級標題；缺題、同題重複、指向未發布題或標題改名未更新時阻擋建置。所有輸出的片段連結再由 `tools/check_output.py` 檢查。這次工作只索引已發布題目及其現有解析，不把新增導覽當作重新完成醫學審查。

## 分類邊界

- **官方歷屆真題：** 核對考選部來源後才設定 `exam` metadata，才會出現在依年度編排的專用目錄。
- **自編練習、跨題型教學、疾病概念文章：** 保留原有題目或文章內容，但不應冒充某年度的官方試題。可透過主題閱讀與搜尋查找。
- **官方原題與現行醫學知識：** 年份身分永不改變。即使後來指引更新，應註明「原年官方答案」與「今日臨床判斷」的差異，而非改寫原始考試身分。
- **來源與 QA：** 結構測試、原始試卷核對、Figure／Table 驗收與獨立醫師審查是不同門檻；所有已存在的門檻繼續保留。

後續若需要針對單題建立獨立詳解，先核對唯一鍵與現有跨題文章，避免同年度、同試卷、同題號在網站同時存在兩個互相矛盾的正式版本。
