# Clinical OS／Master Prompt v5.1｜統一運作契約（整合候選）

日期：2026-10-21（Asia/Taipei）｜狀態：**候選整合契約，尚未構成 v5.2 能力驗證**。
本文件是操作收斂，不另建 Agent 平台、不重寫已存在的 EPQC／LEC、不修改歷史作者原稿、不自動發布網站。保留現有各契約專職權責。

## 0. 核心判準

> 同一個當代模型，在相同可用原始資料、工具與工作預算下，加入 Clinical OS 後，是否能**穩定提升可核實的醫學／教學決策品質**、減少重大錯誤與人工介入，且收益大於執行與維護成本？

不得以單篇好文章、單次 AI 自評、網站建置成功或 Prompt 變長宣稱成立；也不把作者原稿早已論證的內容認領成 AI 發現。

本階段主驗收優先量測重要遺漏、誤判／誤報、不必要修改、新引入錯誤、原有正確推理保留，以及實際人工修稿、追問與維護成本。有根據且必要的新橋接另報，不要求每篇必須新增洞見。與 Native、Evidence-only 比較時，固定實際模型版本、effort、來源、工具及總工作預算；額外讀契約與查核的成本一併計入。

系統的長期資產只保存：無法可靠重建的**原文與版本、原始證據定位（含圖表）、作者／審稿決策、重大失敗及其驗證案例、不可妥協的品質契約**。研究、寫作、脈絡重建、選用工具與展示形式預設交由當代 AI 自主完成。若簡化的模型＋契約已足以穩定完成工作，刪除沒有可測增益的規則／模組。

## 1. 單一架構，五種責任

| 層 | 目的 | 既有真實工作來源 | 不可混同 |
|---|---|---|---|
| Source & Provenance | 保存作者原稿、醫學原書、版本與權利 | 原稿 content/xiaoma-reading/originals；私人 archive；來源稽核 audit | 取得全文 ≠ 作者最終認可版 ≠ 醫學內容已查核 |
| Knowledge & Editorial | 從臨床問題辨認前提、機轉、證據、決策；產生獨立 AI 新教材 | content/clinical-os、content/xiaoma-internal-medicine；EPQC | 原創文章 ≠ AI 整合稿；摘要 ≠ 新知識缺口 |
| Evidence & Safety Audit | 查原文／Figure／Table／註腳、因果邊界、最新適用條件、危險反例 | audit/；Pocket Medicine 第九版原 PDF 與對題 guideline／研究 | 找到引用 ≠ 真正看過圖 ≠ 高風險主張正確 |
| Reading Product | 將同一知識模型提供可連續閱讀的核心、推理、深究三層 | LEC；site/pages.json；Markdown → Python build | 功能與設計完成 ≠ 學習速度／正確率提升 |
| Evaluation & Operations | 盲測增量、追蹤失敗、最小人工維護、選擇 Lite／Full | experiments/README.md；Git 版本／CI | 技術回歸通過 ≠ 編輯能力／臨床效益被驗證 |

這五層是**責任邊界，不是五個常駐 Agent 或五套資料庫**。正常任務只啟用必要層，醫學安全與出版邊界則始終適用。

## 2. 統一任務循環（對話、Work、Codex 共同遵守）

**T0 釐清產物與風險。** 自主判斷目前是原文回收、來源反查、跨篇知識整合、獨立教材、教學體驗比較，還是發布。辨識臨床高風險分支及是否需直接發布；未明確授權出版的實驗採 HOLD。優先沿用現有檔案，避免開新系統。

延續任務時，以當前來源及相關最新使用者決策重建本次交付、尚未完成項與完成證據，不要求使用者重述已知共識。重要的範圍、來源身分或驗收條件改變時，按需檢查受影響正文、程式、測試與發行設定；修正已與新決策衝突的舊要求，並保留仍有效的醫學及品質門檻。只查本次受影響範圍，不每回合全庫稽核，也不新增長期人工台帳。真正的新任務依使用者要求執行，不用舊 backlog 阻擋。

**T1 固定輸入證據。** 依任務取回可追查的完整作者稿、來源版本、同題評語、原書 PDF、對題指南與試驗。指定 Pocket Medicine 原始 Figure／Table／圖說／腳註／分岔時，必須目視查圖；只讀檢索段落不可記作圖像查核。每項註明「全文／原圖／文字與圖說／摘要／尚未取得」的實際層級。來源存取失敗明說，不能用自編補原文；圖像公開使用需另查權利。

**T2 反向審查知識增量。** 先完整理解作者／教科書原來做了什麼，將候選概念橋分類：
- **A 已充分論證**：保留、建立精確連結，不重寫並認領成「新發現」；
- **B 跨篇已出現但未連接**：建立最短必要導航或銜接；
- **C 確實欠缺且有證據支持**：補入會改變理解或決策的中介；
- **D 必要限定／校正**：辨識單點量測誤推、適用條件、例外、時間差或證據等級；
- **X 缺乏來源支持**：排除或明確列待證，不得寫成定論。
以反例驗證是否真的改變判斷。避免為建 Claim Graph 而建圖：預設只按需重建依賴，持續全域圖需 Lite／Full 實測增益才能成立。

修改幅度依證據選擇：保留、精確連結、局部更正、補必要中介、另寫整合教材、重建核心模型或 HOLD。擬大幅重構時，先用原稿及來源提出保留架構、僅局部補足的最強可行方案，再比較是否充分修復。可靠證據已推翻核心前提時，必須重建受影響推論；歷史原稿另行保真。

**T3 依內容本性寫作。** 以「臨床問題 → 必要前提 → 生理／病理機轉 → 新證據如何改判 → 決策與剩餘問題」為理解架構，不是固定五段模板。必須達 EPQC 七軸、硬性退稿條件；HCM／ACS 作認知品質錨點而非文風模仿。具有危急後果時，重症轉折須從同一條因果敘事自然長出，不堆獨立 ICU 附錄。先備解釋就地補，不用互動取代必要文字。作者原文不可被 AI 新稿覆蓋。

**T4 審查與失效修復。** 對高影響主張執行來源、原圖、數值、適用對象、反事實與資料身分核對；能取得獨立 reviewer 時，盲審優於原作者同輪自評。辨認引用錯置、把相關當因果、臨床風險漏掉、補造病例、跨篇抄回同義段、互動造成錯誤確定性，以及 tool failure 被當成功。先修根因，再局部修稿與回歸；反覆出錯才提出可評測的持久規則。P0／P1 未關閉即 HOLD，不以平均評分補償。

**T5 根據交付型別發布或保存。** 正稿封存及其版本依據保存在私有庫。實驗稿留分支與證據紀錄，不進 site/pages.json。可公開的新作品先檢查事實／審稿／版權／隱私與權利，再加入既有明列出版清單；CI → Cloudflare 部署 → 公網實際存取分開確認。技術檢查只能聲明技術通過。沒有必需內容時不要為了更新網站而先做頁面。

交付前回對 T0 的同一要求：稿件、來源查核、測試、Git 整合、部署與送達各依實際證據報 completed／partial／HOLD。排程或工具記錄的 completed 不等於教材已交付；沒有對應產物時繼續查明或報具體阻擋，不能推定從未執行或已成功。公開邊界須檢查乾淨輸出、搜尋及反向連結，不能只隱藏導航。沿用唯一 site/pages.json；問題稿 HOLD 當篇，不以全量回收或系統增益未證明阻擋其他合格教材。

**T6 評估是否值得保存機制。** 用 experiments/README.md 的前註冊、配對控制、反事實、安全失誤及人工成本判斷外部規則的淨增益；失效不能只記 log，應成為下次同類工作可重測的最小 regression case。跨模型升級後重跑代表性測試，通過後可刪弱增量規則，回退保留版本歷史。

## 3. 系統何時真正提供「新洞見」

每一項所謂新增洞見至少應留下：
1. **前狀態**：作者原稿／Pocket／既有教材實際說到哪一層、哪個 Figure 或原句已涵蓋；
2. **增量類型**：A/B/C/D/X，以及是否會改變臨床推論或只是敘事整合；
3. **必要證據**：來源範圍與逐圖核對狀態；相關性、因果性、適用條件分開；
4. **反事實測試**：條件變了後，是否真正改判而且維持安全；
5. **成本**：新增文字或操作是否比精確跨篇連結更有價值。

目前 HF × LVEDP × DCM × Diuretics 已有可用先導稽核：congestion≠perfusion、EF≠CO、early natriuresis≠decongestion 是作者原已建立的 A；renal venous back pressure 等才是可能 C；單點 LVEDP 推 stiffness、PAWP 當 LVEDP 則是 D。這個「不搶走作者已完成的貢獻」能力，應在所有主題重用。

## 4. 發布與自主性界線

- **研究自主**：允許 Agent 自行搜尋原稿、必要文獻、檢驗隱性依賴、主動退稿、提出修改及修復工具失敗；不為每次普通研究要求使用者安排手動步驟。
- **保真自主受限**：對歷史已在 Facebook 發布的文章，以**實際取得、核對全文與發布識別的 Facebook 版**作作者已發表版本的預設 canonical；無法取得時只標來源快照，保持 published-version pending。不可自行改寫歷史原稿，也不能將作者曾評為好看的 AI 草稿取代真正已發表文字。
- **安全自主受限**：高風險臨床內容若有實質未解錯誤，禁止視為完成醫學審核；AI 自評與技術 CI 均不是真人專科審查替代。
- **編輯自主與出版門檻**：對**新製、尚無歷史 Facebook 發布版**的 AI 整合教材，Agent 在已授權的發布範圍內可自主選版、退稿、修訂及依 EPQC／事實來源／安全／權利檢查作 **AI editorial approval**，無須每篇向使用者索取常規逐段核准；但不能自稱作者親自審過、真人專科同儕審查或讀者學習實測。跨篇教材原則上以能獨立完成臨床因果主線的 group-ready 發行；單篇已完整解決單一問題時可 standalone release。未通過者或實驗稿不得加入 site/pages.json，既有已核實歷史原稿可依保真與安全條件獨立典藏；公開平台的實際發布仍需通過技術、隱私、版權及醫學閘門。
- **內容排除**：心外／外科、顱內動脈瘤、實習心得不加入「小麻閱讀」公開候選；他們可保留為私人學習脈絡。

## 5. 優先序及止損

P0 **修實際資料身分不一致**，建立唯一可信進度指向；保持已封存舊 checkpoint 不改造歷史。当前 main 已具七個 originals 檔案（含 HCM），21 筆對話稿中六篇已移入、十五篇待轉存；此前 README 的四篇是過時快照，不能作總數真值。

P1 **用已讀四篇 HF 群驗證新增橋樑**：集中確認 Figure、研究補充、EDPVR／PAWP／venous back pressure 的真正來源增量；不重寫已完整的原作者教學。

P2 **原生 GPT vs 薄證據契約 vs Clinical OS Lite 配對盲測**：同模型、同來源、同工具條件，至少跨三類未看過的新主題；醫學安全為硬閘門，人工總耗時作共同主指標。若增益不穩定，優先精簡而非加模組。

P3 **Tamponade 靜態 vs 有意義互動**：固定證據與教學目標，實測理解時間、臨床遷移、安全錯誤、認知負擔，再決定是否擴充互動。

P4 **Lite vs Full／T5交接／T6再修訂**：只在重要漏修的成對驗證顯示 Full 的持續保存成本值得時，啟用全域圖；不把既有原型的主張集合當永久 schema。

P5 **2027 考試時程**：小麻內科國考服務 2027 年 2 月台大筆試之提前完讀及 2027 年 6 月醫師二階；122 章／82 日只是路線索引，不是已掌握或高品質出版的完成數字。真題需題幹、圖像、官方標準／更正答案及擷取 QA 分別驗收。

停止條件：若一項新架構、Agent、互動元件或永久資料欄位在受控比較中不能降低重要錯誤、人工總耗時或經驗證的理解成本，停止擴張並回退至原生能力＋品質契約。此決定需記原因、對照及回退版本，不把單次例外擴成永久規範。
