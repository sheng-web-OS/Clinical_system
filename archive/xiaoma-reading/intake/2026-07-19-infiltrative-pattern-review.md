## 本篇核心模型與新增性

- 【A，原稿已完成】ALP-predominant phenotype 是 **observable biochemical signal**；`infiltrative` 是一個根據臨床與檢查所提出的 **underlying tissue hypothesis**，不是另一類和 cholestatic 並排互斥的生化指標。
- 【A，原稿已完成】malignancy、granuloma、abscess、medication 並非同一分類維度；不能當互斥病因清單。
- 【A，原稿已完成】正常或接近正常的 bilirubin 與 aminotransferases 不能推導沒有廣泛肝內病變，影像陰性亦不直接排除 diffuse / microscopic disease。
- 【B，跨篇連結】承接 2026.07.18 liver tests 與 2026.07.19 cholestasis 文章；上游篇章尚是 conversation-only，未經 Git 實際回收，不要在網站假設連結存在。
- 【D，需要限定】「ALP 已升高，因此浸潤破壞膽汁微環境、造成 bile-acid-induced ALP synthesis」是合理的 **可能機轉模型**，非每個 infiltrative process 均已被證明遵循的路徑，也不代表必有可測的 microscopic cholestasis。部分發炎、藥物或膽道病因可有相同生化表現。
- 【D，需要限定】GGT 升高支持肝膽來源，並不能單獨確立具體肝膽病因；GGT 也可能受酒精、藥物等影響。適當時可考慮 ALP isoenzyme differentiation。
- 【D，需要補齊】確認 ALP 來自肝膽系統後，不能直接跳到「無大型膽管阻塞 → occult infiltration」。仍需根據臨床情境評估藥物與補充品、PBC（例如 AMA）、PSC / IgG4-related disease 等一般 intrahepatic cholestasis 病因，並依影像與病程調整可能性。
- 【D，原書圖的潛在風險】圖的 “SPEP to r/o amyloid” **不能解讀為 SPEP 陰性即可排除 hepatic amyloidosis**。若懷疑 systemic AL amyloidosis，血清／尿液免疫固定電泳與 serum free light chains 等檢測會比單一 SPEP 更完整；最終組織診斷及 amyloid typing 需依情境取得。是否活檢與取樣位置要考慮風險和臨床可能性。
- 【D，反例】已有 biopsy-proven hepatic amyloidosis 並且幾乎完全取代肝臟結構、但 liver chemistries 仍正常的病例（2020 case report）；證明 **ALP 大小與浸潤空間負荷不是固定比例**，不能把它寫成每個病變都先出現 ALP 升高。

## 推論壓力測試

1. ALP 高、GGT 正常 → 先考慮骨、其他來源；不沿用 infiltrative liver workup 作預設。
2. ALP 高、GGT 高、超音波未見膽管擴張 → 不是已確診 infiltration；藥物、PBC、small-duct / inflammatory disease、PSC 等需依情境鑑別。
3. Imaging 未見 mass 但持續不明原因 hepatobiliary ALP elevation → 重新估計 diffuse / microscopic disease 與其他病因，必要時進階影像、血清學及選擇性 biopsy；**不把 biopsy 變成每例固定下一步**。
4. 患者肝大但 ALP／bilirubin 皆正常 → 不能以正常肝臟檢驗排除顯著 infiltrative process。
