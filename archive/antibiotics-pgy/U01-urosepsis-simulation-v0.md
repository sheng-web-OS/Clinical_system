## 第一幕：01:10 的值班電話（T0）
護理師：「68 歲男性，糖尿病、CKD stage 3、攝護腺肥大，剛剛畏寒發燒 39.1℃，右腰痛，心跳 124、呼吸 26、血壓 92/56。平常可以對答，現在反應較慢。請問要不要先開抗生素？」

立即查到的資料：肌酸酐 2.0 mg/dL（近一個月基線約 1.3）、乳酸 3.8 mmol/L、尿液白血球明顯增加。過去兩個月曾因尿路感染培養出 ESBL E. coli（該次完整 susceptibility panel 待調閱）。曾有反覆尿滯留。腎臟超音波初步顯示右側 hydronephrosis，不能排除輸尿管結石阻塞。今天血/尿培養尚未採集；病人藥物過敏記錄是「penicillin allergy」，反應型態未知。現院當期 urinary-source antibiogram / restricted drug rule 尚未取得。

**題 1（先不看解析）**：請用 90 秒條列前三個行動、需立即通知哪些人、你要在開藥前立即核對的六項資訊。說明哪些事情不可等到影像或培養完成。

**題 2**：在「懷疑感染、循環不穩、過去 ESBL 分離株、AKI、可能阻塞」條件下，你傾向哪一類 empiric coverage？請至少提出兩個候選策略與不選擇某個較窄/較廣療法的理由；不要在未查證時虛構本院首選或劑量。若只有 pyuria，你還會作出同一決策嗎？

**題 3**：寫出可供主治/藥師核對的醫囑草案欄位：generic name / indication / drug selection rationale / dose / route / interval / infusion / first-dose timing / allergy characterization / dosing weight / current creatinine trend / CrCl method / loading-vs-maintenance / interactions / monitoring / local authorization。**未經兩階段原始來源＋本院規範核驗者填「PENDING VALIDATION」，不能編造數字。**

### T0 參考推理（非直接處方）
- 現在最急的是**高度疑似尿源性嚴重感染且有器官功能惡化訊號**，同時處理復甦與求援、採可迅速取得的血/尿檢體、及時給予有合理機會涵蓋致病菌的 empiric 抗菌藥；不可為取得所有化驗或等待培養而延誤高危患者的處置。
- 過去 ESBL E. coli 為重要抗藥性線索，近期培養與藥物暴露會改變 coverage 的先驗機率；選擇必須兼顧病況嚴重度、感染部位、既往 AST、藥物禁忌與當院規則。不能從 ESBL label 本身推論所有療法的當次適當性；在不穩定/高風險情境，選擇具有可信 ESBL 活性的方案需與主治、藥師/感染科及院內管理規則核對。
- **疑似感染性阻塞的腎臟不是單靠抗生素就能解除的病灶**。同步緊急評估泌尿科減壓/引流；有低血壓/精神狀態改變/AKI 時不能設定「等 48 小時看看」。
- 單次 BP 及 lactate 高不足以自行宣稱已達成「septic shock」診斷的所有要件；仍應依現況啟動急重症處置並密切再評估。
- allergy 要確認「哪個藥、多久以前、何種表現、是否曾再次使用」；「不詳」也不能等於「肯定安全」或「所有 β-lactam 絕對禁用」。給藥安全界線需要臨床即時共同決策。
- AKI 時推估腎功能有不確定性，first loading vs maintenance 也不等價；任何固定 mg 或 qxh 都需要患者與藥物資料、權威參考、當院本地規範的交叉核實。

## 第二幕：T+6（不能等 T+48）
血壓進一步下降，尿量下降，病人仍昏沉；已啟動支持處置，但泌尿道仍未解除阻塞。新取得 CT（若當下風險允許）支持右側阻塞性尿路感染。

**題 4**：即使已給對可能有效的第一劑，現在什麼問題依然沒有解決？哪些臨床變化應立即升級？假設當天腎功能繼續惡化，後續維持劑量如何重新核對？

**參考要點**：儘速請泌尿科處理疑似感染性尿路阻塞；評估 ICU/主治處置、器官支持與連續監測。這不是將感染藥物表再加兩欄就能處理的問題。

## 第三幕：T+48（兩種分支）
尿液與血液培養均呈 **E. coli**，情境設定的 AST：ceftriaxone resistant、meropenem susceptible、TMP-SMX susceptible（**全部為合成題目，不是本院發生率或臨床處方憑據**）。

- **路線 A**：病人已完成源控制、生命徵象穩定、意識恢復、尿量和腎功能趨勢改善，能口服且吸收可靠。
- **路線 B**：仍有阻塞、持續低血壓或持續器官惡化。

**題 5**：分別說明是否可以由 empiric 轉 definitive、何時能採用 oral agent、療程從哪天算、何時重新檢查來源控制。**不要單靠「S」這個藥敏字母決定口服轉換**：要考慮感染部位/菌血症、足夠血與組織暴露、腎功能、重要交互作用及臨床穩定性。持續不穩定時不能為配合 48–72h 行政時鐘而機械降階。

## 反事實情境（每個都要重新作決策）
1. **無症狀菌尿**：有 Foley、尿培陽性與 pyuria，但沒有可歸因尿路感染的症狀/全身表現，亦無特定例外。辨認 ASB/colonization，避免陽性培養＝一律抗生素。
2. **加重 AKI／循環惡化**：用已知來源逐一核對 loading vs maintenance、腎功能變動、必要 TDM、何時立即升級；不能只查固定 eGFR 表。
3. **即時型嚴重 β-lactam 過敏疑慮**：確認過敏史可信度與嚴重性，在高危感染條件下透過主治/感染科/藥師共同確定實際可用方案；不得在無資料下直接猜替代藥物劑量。
4. **血培結果與假定尿源不一致**：回到找 source、重新檢體/影像/裝置及污染判斷；不可因初始敘事就排除競爭感染源。
