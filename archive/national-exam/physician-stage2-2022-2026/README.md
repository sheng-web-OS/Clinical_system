# 臺灣醫師第二階段國考｜近五年官方試題典藏

**範圍：2022–2026（民國 111–115 年），每年第一次與第二次，共 10 梯次 × 醫學（三）至醫學（六）＝40 份試卷。** 只包含醫師第二階段；不包含醫師第一階段、中醫、牙醫與藥師。

## 來源與資料層級

- **官方來源**：考選部「考畢試題查詢平臺」；Q 為試題 PDF，S 為標準答案 PDF，M 為考選部發布更正時的更正答案 PDF。
- **manifest.json**：40 份試卷的來源索引。此時只代表官方考試頁面已找到，**不代表 PDF 已下載**。
- **raw/[paper-id]/**：下載驗證成功後保存的官方原始 PDF，不修改原檔。
- **extracted/[paper-id]/**：機器抽取的逐頁文字。圖片、心電圖、表格可能遺失，不等於完整題庫。
- **ingestion-report.json／INGESTION_STATUS.md**：實際下載成功數量、失敗、PDF SHA-256、原始連結及提取狀態。完整率以此為準。

原始資料來源：**考選部**。官方網頁聲明：「本網站資料，歡迎朋友連結使用。但引用時，請註明資料來源並請確保資料之完整（包括本項宣示在內），均不得任意增刪」。本典藏置於私人 GitHub；公開教材只連向考選部，並以題號、作者原創解析銜接學習，不直接散布原始題卷。

## 操作

在 repository 根目錄執行：

    python -m pip install pypdf
    python tools/import_physician_stage2.py --extract --workers 4

或於 GitHub Actions 手動執行 Archive Physician Stage-II Exams；自動執行成功後，來源 PDF、文字衍生檔和狀態報告才算實際收錄。當伺服器拒絕下載或回傳 HTML 時必須記錄失敗，不得默認已典藏。

## 分析品質檢核

1. **真題完整性**：核對實際題數、頁數、原圖、題號、SHA-256；不能只看到可抽取文字就宣稱題卷完整。
2. **答案有效性**：標準答案及更正並列保存；更正可能包含多個有效選項組合、整題送分等，不可強行壓成單一 A/B/C/D。
3. **逐題結構化**：題幹、選項、圖像、題與題相依關係需追溯原卷與頁數；機器抽取尚未審核時標記為 unverified。
4. **知識體系分析**：題目連到「臨床問題 → 前提知識 → 機轉 → 判讀／決策 → 當代證據」，並區分原年度正確答案與現行臨床指南更新；以考頻輔助編輯，不取代臨床重要性。

**與 Clinical OS 的邊界**：這裡是國考官方來源典藏，不是小麻原創正文，也不是已可直接公開的教材。先確立原始資料完整性，再做考點聚合與醫學內容審稿。
